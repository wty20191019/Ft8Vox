## 1. 30 秒上手

| 步骤 | 做什么 | 去哪 |
| --- | --- | --- |
| 1 | 填**呼号**与**网格**，选**波段与频率** | 设置 → 台站 |
| 2 | 选输入 / 输出设备（系统默认或 USB 声卡），调**输入增益** | 设置 → 音频 / 电台（仅 VOX） |
| 3 | 回操作页：首次需点一下解码列表中间的提示来授权麦克风，之后自动开始接收 | 操作 |
| 4 | 点 CQ 报文卡片 → **左滑「呼叫」**（或详情里按「呼叫」），再打开抽屉条上的**「发送总开关」** | 操作 |
| 5 | 通联完成后自动写入日志；可导出 ADIF | 日志 |

> **重要**：发射的唯一闸门是**「发送总开关」**（默认关＝只接收）。本应用**没有**「确认发射」弹窗，点下即排程；所以打开总开关前请先确认电台已就绪。

## 2. 它是什么 / 不做什么

**Ft8Vox** 把 Android 手机变成一台 FT8 / FT4 终端：

- **接收**：采集电台音频 → 实时解码 → 瀑布图 + 解码报文列表（SNR / DT / DF / 报文 / 实体 / 距离）。
- **发射**：手动（CQ / 应答 / 信号报告 / R 报告 / RR73 / 73；CQ 前缀可选 `CQ DX` 等）或**自动程序**（自动选台、自动走完整段 QSO）。
- **日志**：通联自动落库，自动写入距离备注；ADIF 合并导入 / 导出。
- **地图**：离线世界地图（可纵横循环），显示解码 / 已通联 / 已确认网格、CQ 旗与信号连线。

**明确不做**（详见 [§17](#17-已知限制)）：

- **不做 CAT**：不能控制电台频率 / 模式 / PTT，发射依赖电台 **VOX** 或手动 PTT。
- 不做 Hound / Fox（DXpedition）、FST4、竞赛报文、在线地图瓦片、在线日志上传、接收频率自动窄带过滤、逐条呼号的精确 DXCC。

## 3. 硬件接线与前期准备

### 3.1 两种音频接入方式

| 方式 | 接法 | 设置（设置 → 音频 / 电台） |
| --- | --- | --- |
| **声学耦合** | 手机扬声器 ↔ 电台麦克风；电台扬声器 ↔ 手机麦克风（贴近但不接触） | 输入 / 输出设备都选「系统默认」 |
| **USB 声卡 / OTG** | 手机 USB → 声卡 → 电台 DATA / ACC / 麦克风插口 | 输入 / 输出设备选该 USB 声卡 |

> - USB 声卡**插入后需要重进设置页刷新**设备列表。
> - 设备 id 可能随插拔 / 重启变化；若失配，界面回退显示「系统默认」，音频仍走系统默认。
> - 声学耦合时把手机音量调到中等：太小时解不出，太大时会削顶（瀑布整片亮、SNR 反而变差）。

### 3.2 权限

| 权限 | 用途 | 说明 |
| --- | --- | --- |
| 麦克风 | 接收解码（必须） | 未授权时操作页空态会提示，点一下即申请 |
| 通知（Android 13+） | 前台服务常驻通知 | 拒绝也不会中断接收，只是看不到通知；可在系统设置里补开 |

### 3.3 时间

FT8 / FT4 按 UTC 时隙工作，**手机时间必须准**：

- 建议系统「自动确定日期和时间（网络时间）」打开，或用 NTP 同步工具把误差压到 1 s 内。
- 底部状态条显示「时间同步」；当最近一条解码的 **DT 绝对值 ≥ 1.5 s** 时变红字「时间不同步」。

### 3.4 合规

确认发射频率 / 功率符合所在国家 / 地区无线电管理法规，并持有相应操作资质（见 [§18](#18-合规与免责)）。

## 4. 首次设置（必须做）

### 4.1 台站（设置 → 台站）

| 项 | 说明 |
| --- | --- |
| **呼号** | 必填（为空时发射按钮不可用，解码列表也会提示「未设置呼号」）。自动转大写 |
| **网格** | Maidenhead 网格，可留空；填了必须合法（2 / 4 / 6 / 8 位，如 `JN25`、`JN25AA`）。用于距离、方位与地图定位 |
| **波段与频率** | 无 CAT，需人工指定。列表里选各波段常用 FT8/FT4 刻度频率，也可「自定义波段与频率…」。仅用于记录与 ADIF |
| **备注** | 写进通联日志备注（可选） |

### 4.2 音频（设置 → 音频）

| 项 | 建议 |
| --- | --- |
| **输入设备** | 声学耦合选「系统默认」；USB 声卡选对应设备。运行中切换需重新「开始接收」 |
| **采样率偏好** | 一般「自动」；设备实际值以底栏 / 音频速览为准 |
| **输入增益** | **热生效**。对着电台的常规信号，把「输入电平」调到约 **−30 ~ −10 dB** 一带（不要顶到 0） |

### 4.3 电台（仅 VOX）（设置 → 电台）

| 项 | 说明 |
| --- | --- |
| **发射前导音** | 发射前先放一段单音，让电台 VOX 抢先触发（默认关） |
| **前导音时长** | 单音时长（0–2000 ms，默认 200） |
| **输出声卡** | 发射音频输出设备；USB 声卡插入后重进本页刷新 |
| **输出音量** | 发射音频的**数字衰减**（−30…0 dB，0 = 数字满幅，只能往小调）。对报文与测试音都生效 |
| **测试音** | 发 1 kHz 单音 2 s，用于联调 VOX 键控与音量 |
| **PTT 延迟** | 数据前插入的静音，留给声卡路由 / 电台起键（默认 50 ms） |
| **看门狗超时** | 发射写入卡死保护；实际会抬高到本次发射时长以上，不会截断合法发射 |

> 本应用**不做 CAT**，无法读取电台真实的 PTT / VOX 键控状态；VOX 键控失败时 App 无从感知。

## 5. 界面总览

### 5.1 顶栏（固定，56 dp）

| 区域 | 内容 |
| --- | --- |
| 左 ☰ | 菜单：**波段与频率** / **模式**（FT8·FT4，切换会重建引擎、接收短暂中断）/ **自动程序** / **设置** |
| 中第 1 行 | 当前 **UTC 时间** |
| 中第 2 行 | `刻度频率 MHz · 协议 · TX：n`（n = 我方发射时隙奇偶 0/1；处于我方发射时隙时高亮） |
| 中第 3 行 | **待发 / 发射中** 的报文全文（只在我方发射时隙出现）。**发射中显示的是本条实际在播的报文，不会中途变化** |
| 右 | 绿 / 红状态点 + 「音频」图标（音频 / 电平速览：输入输出设备与采样率、输入增益、输出音量、输入电平、前导、看门狗） |

### 5.2 底部状态条（常驻）

`● RX/TX · 电平 xx dB · 解码 n/min · 总数 n · QSO n · 队列 n · 时间同步`

- **RX / TX**：绿点＝接收，红点（脉动）＝正在发射。
- **电平**：输入电平（dBFS）；未接收显示 `--`。
- **解码 n/min**：最近 60 秒的解码条数。
- **总数**：本会话累计解码条数。
- **QSO**：日志总条数。
- **队列**：待发的一次性报文（0 / 1）。
- **时间同步**：DT 超 ±1.5 s 时变红字「时间不同步」。
- 内容多时可横向滑动。

### 5.3 四个 Tab

**操作**（接收 / 发射主界面）· **地图** · **日志** · **设置**。切换 Tab **不会**中断接收与 QSO（三个 ViewModel 都是 Activity 作用域）。

## 6. 操作页：接收与瀑布图

### 6.1 开始 / 停止接收

- 进入操作页并已授权麦克风 → **自动开始接收**。
- 未开始接收时，解码列表空态点一下即可授权并开始。
- 接收中按**返回键** → 退到后台**继续接收**（弹短提示）；要真正停止，用通知栏的「停止接收」。

### 6.2 瀑布图

| 元素 | 含义 |
| --- | --- |
| 顶部 4 dp 色条 | 当前时隙奇偶：**蓝＝偶数周期(0)**，**橙＝奇数周期(1)** |
| **红线** | **发射频率 = 报文下边频**（唯一可调频率）。**单击 / 水平拖动**即把红线移到该处 |
| **半透明红条** | 红线右侧，标出**本条报文实际占用的带宽**（FT8 ≈ 50 Hz、FT4 ≈ 83 Hz），即 `红线 … 红线+50 Hz` |
| 红框 | 正在发射时的整圈提示 |
| 右下 `TX nnnn Hz` | 当前发射频率（**下边频**）读数 |
| 贴底进度条 | 当前时隙进度 |
| 下方频率轴 | 左 / 中 / 右三个刻度（Hz） |

- **长按瀑布**：把红线移到按下处，并打开**离该频率最近的一条解码详情**。
- 频谱**不支持捏合缩放**（设计如此）。

### 6.3 筛选条（瀑布下方）

- 最左 **🗑 清除**：清空本会话解码列表（只清显示，不写日志、不影响自动程序）。
- **Chip（可多选）**：`全部` / `与我有关` / `CQ` / `回复` / `73` / `已通联`，每个带角标计数。
  - `全部` 互斥：点它＝不过滤；点其它任意项会自动取消 `全部`，其余项之间是**并集**。
- 最右两个图标（与最左的 🗑 对称）：
  - **🔍**：展开呼号 / 前缀 / 网格过滤输入框（逗号分隔，可多个）。
  - **⭐**：打开 / 收起「**关注呼号列表**」面板（见 §6.5），图标旁角标＝当前关注数量。
- 至少保留一个筛选项，否则列表提示「请至少开启一个筛选」。

> 注意：「关注」**不是**解码筛选，而是**一份呼号名单**（⭐ 打开后可看 / 可删）。

### 6.4 自动翻到最新

新解码到达时列表会自动回到顶部；手动上滑翻看历史会暂停跟随，滑回顶部自动恢复。

### 6.5 关注呼号列表

点筛选条最右的 **⭐** 打开，再点一次（或点面板右上 **✕**）收起；面板盖住解码列表区域，**不占额外一行**。

- 标题行：⭐「关注呼号 n」+ 右侧提示 `左滑呼叫 · 右滑取消关注` + **✕ 关闭**。
- 每行是一个**呼号**（不是解码报文）：呼号 + 本次会话最近一次听到的网格 / SNR / 音频频率 / 时间 / 距离；
  本会话没听过的排在最后，第二行显示「本次会话未听到」。
- **自动收录**进来的呼号在呼号右侧带一个 **「自动」** 小标记（区别于手动长按关注的）。
- **左滑**（露出绿色「呼叫」）＝设为目标并立即呼叫该呼号（与解码卡片左滑同义，需发送总开关已开）。
- **右滑**（露出灰色「取消关注」）＝从名单移除该呼号（该行随即消失；自动收录的也一并移除）。
- 某台**通联完成后自动取消关注**：与其完成一次 QSO 并落库后，该行会自动消失。
- 名单为空时提示：在解码列表**长按某台 →「关注」**，或打开「自动收录 CQ 台」让名单自动增长。

> 名单里的呼号有两个来源：**手动**（解码列表长按「关注」）与**自动**（自动程序里的「自动收录 CQ 台」，
> 每解到一个**本波段还没通联过**的 CQ 台就自动加入；跨波段通联过的台在本波段仍会收录；
> 自动收录封顶 100 个，超出淘汰最早加入的，手动关注的不受此限）。
> 关注名单的作用见 §11.1：它是「自动收录 CQ 台」开关的**例外**——开关关掉时，自动程序仍会呼叫名单里 CQ 台的 CQ。

## 7. 解码列表怎么用

每张卡片两行：

- 第一行：`时隙 0/1` · `SNR dB` · `DT ±x.xs` · **报文**（含我呼号时红色加粗）· 行尾小圆点标记（与我有关 / 当前对手 / 新网格 / 新实体）。
- 第二行：发送方呼号（粗体）· 实体 · 距离 km · 解析的 UTC 时间。
- 左侧 4 dp 色条＝该行的**最高优先级**分类：发射中 / 自己发的报文（黄底黑字）> 与我有关 / 当前对手 > CQ > 已通联 > 重复 > 新网格 > 新 DXCC/ITU/CQ/前缀 > 新呼号 > 普通新解码（绿）。

| 手势 | 动作 |
| --- | --- |
| **单击** | 打开详情半屏：网格 / 类型 / SNR / DT / 音频频率 / 时隙时间 / 距离方位 + 「呼叫」「日志」按钮 |
| **双击** | 跳到**地图页**并定位该呼号 |
| **长按** | 菜单：`呼叫 <呼号>` / `回复 <呼号>` / `查看日志` / `复制消息` / `关注 <呼号>`（已关注则显示 `取消关注 <呼号>`）/ `忽略 <呼号>` |
| **左滑**（露出绿色「呼叫」） | **设为目标并立即呼叫** = 选台 + 对齐对方时隙 + 开始应答（需发送总开关已开） |
| **右滑**（露出灰色「删除」） | 删除这一条（只删显示，不动关注名单） |

> 菜单里的 **呼叫** 与左滑同义（直接发 `<对方> <我> <网格>`）；
> **回复** 按该报文的类型给出正确回复：`CQ` → 应答；定向网格 → 发信号报告；
> 定向报告 → 回 `R<报告>`；定向 R 报告 → 回 `RR73` 收尾（与自动程序同一条路径，人工操作不暂停自动程序）。
> **查看日志** 跳到日志页并把搜索框预填为该呼号（查看以前是否通联过）。
> **关注 / 取消关注** 维护「关注呼号名单」（点筛选条最右的 **⭐** 查看 / 删除，见 §6.5）；照 FT8CN，
> 这份名单**不受「自动收录 CQ 台」开关限制**（开关关掉时，自动程序仍会呼叫名单里 CQ 台的 CQ）；
> 名单里的台**通联完成后自动取消关注**。

> 自己的发射也会被本机解出（**发方呼号就是我方呼号**，整行**黄底黑字**，与是否正在发射无关）；这类自发报文只显示，不参与 QSO 路由（引擎会忽略发方为自己的报文）。

## 8. 发射：发送总开关与发射抽屉

### 8.1 发送总开关（唯一闸门）

- 位置：操作页底部**抽屉条**右侧的开关。
- **关（默认）**：只接收，不发射任何报文（抽屉显示「只接收」）。
- **开**：允许发射，抽屉显示「允许发射」。发什么由「发送」按钮 / 解码卡片手势（手动）或自动程序（自动）决定。
- 每次启动 App **不记忆**这个开关（默认关）；启用自动程序时会自动打开它。
- **没有二次确认弹窗**：点下即排程。

### 8.2 抽屉条（收起态）

```
→ 目标                允许发射   [开关]
  下次发送 <下一次要发的报文全文>
```

- 左 line 1：当前目标（`→ 无目标` 表示未选台）。
- 左 line 2：**下一次会发射什么**的完整报文：`下次发送 <报文全文>` / 无计划时「空闲（无下次发送）」。
  **始终跟着「下一次」变**：发射途中切换目标 / QSO 推进，这里立刻更新（顶栏第 3 行则冻结为本条在播的报文，见 §5.1）。
- 右：允许发射 / 只接收；武装后显示倒计时 `x.xs`。
- **手势**：**向上拖动条身跟手展开**面板（松手按位置 / 甩动速度吸附）；**单击 / 长按**条身也能展开。

### 8.3 展开后的面板

| 区块 | 用法 |
| --- | --- |
| 目标 | 目标呼号 + 网格 + 频率；「取消目标」同时停止发射 |
| 消息类型 | 大按钮（六步）：`1 网格` / `2 报告` / `3 R报告` / `4 RR73` / `5 73` / `6 CQ`；按下即填入自定义框 |
| 自定义 | 直接编辑要发的报文（显示字数 / 75） |
| CQ 前缀 | 4×2 **单选**：空（无）/ DX / ASIA / EU / NA / JA / TEST / POTA；点一下选中，**长按编辑**前缀文本。选中的前缀由**所有 CQ** 使用（`CQ DX BG7ZJW OM89`） |
| **发送**（大按钮） | 发**自定义框**内容 → 空则按目标默认（无目标＝呼 CQ（带当前前缀），有目标＝应答）。发射中变红「停止发射 · x.xs」，点按即中止 |
| 底部说明 | 当前能不能立即发（本时隙剩余时间够不够播完报文） |

**「立即发」还是「排到下一个周期」**：报文波形 + 前导能在本时隙剩余时间内播完 → 本时隙立即发；否则排到下一个我方发射周期。

### 8.4 停止发射

面板大按钮变红后点它，或用「取消目标」。中止走 native 无锁路径，不会卡住界面。

### 8.5 发射途中换目标（本时隙够播完就当场重发）

正在发射时改目标（点 CQ / 应答一条新的解码 / 发一条自定义报文），**只要本时隙剩下的时间还够完整播完
新报文**（前导 + 0.5 s 保护间隔 + 报文时长），应用会立刻作废正在响的那段音频、当场把新报文重新生成并
发出去 —— 不必白等一个完整周期（FT8 30 s）。时隙开头约 1.3 s（FT4 约 1.4 s）内改目标才来得及；
过窗后改目标只更新抽屉收起条的「下次发送」，本段照旧播完，新报文排到下一个我方时隙。

> 顶栏第 3 行在发射中**冻结为正在播的报文**（避免显示的与真正在天上的不符）；「下次发什么」看抽屉
> 收起条的第二行。这两者在换目标后会一起变成新报文。

## 9. 手动完成一次通联（QSO）

### 9.1 应答别人的 CQ（最常见）

1. 在解码列表里点开一条 `CQ <对方> <网格>`，**左滑「呼叫」**（或详情里按「呼叫」）。
2. 确认抽屉里的**发送总开关**已开、目标正确、报文为 `下次发送 <对方> <我> <网格>`。
3. 你在对方相反周期自动发射；看顶栏第 3 行确认在发什么。
4. 对方回你**信号报告**（如 `我 对方 -12`）→ 自动发 `对方 我 R<我测到的报告>`。
5. 对方回 `RR73`（或 `73`）→ 通联完成，**自动写入日志**。
6. 日志页可查看 / 编辑 / 导出。

### 9.2 自己发 CQ

1. 抽屉面板里按 `6 CQ`（填入 `CQ 我 网格`，带当前「CQ 前缀」），再按大按钮**发送**；或直接按「发送」（无目标时默认呼 CQ）。
2. 有人回应后，流程同上（你会收到 `我 对方 <网格>` → 自动发报告 → …）。

### 9.3 随时发一条自定义报文

在「自定义」框输入（界面上限 **75 个字符**；FT8 报文为 75 bit，标准报文实际通常 ≤ 13 字符），按**发送**即可。

### 9.4 报文格式速查

| 场景 | 报文示例（我=`BG7ZJW`，对方=`JA1ABC`，网格=`PM95`） |
| --- | --- |
| 呼叫 CQ | `CQ BG7ZJW OM89`（选了 CQ 前缀则 `CQ DX BG7ZJW OM89`） |
| 应答 / 报网格 | `JA1ABC BG7ZJW OM89` |
| 发信号报告 | `JA1ABC BG7ZJW -12` |
| 确认收到报告 | `JA1ABC BG7ZJW R-12` |
| 结束（Roger / 73） | `JA1ABC BG7ZJW RR73` 或 `… 73` |

> 本应用遵循标准 FT8 语义：**收到对方的 `R<报告>` 即视为对方已确认，直接回 `RR73` 并记日志**，不会再把 R 报告回一遍。

## 10. 时隙、周期与时间校准

- **FT8**：15 s 一个时隙；**FT4**：7.5 s。奇偶两个周期交替。
- 顶栏第 2 行的 `TX：n` 是**我方**发射时隙的奇偶；选台时会自动把发射对齐到对方的**相反周期**。
- **同频 / 异频发射**（设置 → FT8 → 同频发射）：
  - 开（默认）＝**同频发射**：选台时红线（发射频率）跟到对方频率，「点谁打谁」。
  - 关＝**异频发射**（split）：发射固定在红线位置，选台不改红线。
- **时隙偏移校准**（设置 → FT8 → 时隙偏移，−2500…+2500 ms）：
  - **整个时隙一起平移**（解码窗口起点 + 发射起点）。
  - 用法：看解码卡片上的 **DT**，把它原样填进去（例如 DT 长期 `+1.5s` → 填 `+1500`），DT 回到约 0 即校准完成。
  - 正值＝推后，负值＝提前。
  - 两端时间都准的情况下一般不用动它。

## 11. 自动程序（照 FT8CN 单档）

入口：顶栏 ☰ → **自动程序**，或设置 → FT8 → 自动程序（同一套面板）。

**没有档位、也没有启用确认框**：打开「**发送总开关**」即启动自动发射，关闭即停。
自动程序的唯一闸门是发送总开关（默认关、不持久化，每次启动都要手动打开）。

### 11.1 选台规则

- **定向报文一律应答**：任何**发给我方**的定向报文（呼叫我 / 给我报告 / R 报告）都优先处理，
  且**不受解码列表页签、搜索框、两个开关、工作阶段的限制**（只有「忽略该呼号」会拦住）。
  因此解码列表怎么筛选都不影响自动应答。
- **本波段已通联的 CQ 台不再主动呼叫**（硬编码，对应 FT8CN `checkQSLCallsign` 的 `where band=?`；
  跨波段通联过的台在本波段仍可主动呼叫）。
- **忙时目标沉默也会应答别人**（FT8CN「三循环」的循环 2）：正在通联某台时，若某一批解码里
  **目标没有回应**、而另有别人呼叫我方，则**转而应答那个人**（换台）；目标这一批有回应时不会被抢走
  （有目标不换台）。这样不会因为「忙着等一个沉默的台」而漏掉真正在呼叫我方的台。
- **CQ 修饰符优先级**：`CQ DX` 最优先，其次是与**我所在区域**（由我的网格粗判 NA/EU/AS/OC/SA/AF）
  匹配的修饰符，再次是其它修饰符，最后是无修饰符；同优先级按解码先后。
- 两个开关都开、且存在未通联的 CQ 候选时，**优先 S&P 应答最合适的那台**；否则自己发 CQ。

> 说明：两个开关 + 一份「关注名单」（手动长按「关注」，或由「自动收录 CQ 台」**自动加入**——本机
> 有意偏离 FT8CN：FT8CN 的「自动关注 CQ」只推送到呼叫列表、不写关注名单）：
> - 都开 ⇒ 自动应答**本波段任何**未通联的 CQ 台；
> - 只关「自动收录 CQ 台」⇒ 名单不再自动增长，且**只**自动呼叫名单里 CQ 台的 CQ（名单是该开关的例外）；
> - 关掉「自动呼叫 CQ 台」⇒ 完全不应答 CQ。
>
> 无论怎样都仍会自己发 CQ，且对方直接呼叫我方时一定应答。关注名单可点筛选条最右的 **⭐** 查看（见 §6.5）；
> 名单里的台**通联完成后自动取消关注**。

### 11.2 四项设置

| 项 | 说明 |
| --- | --- |
| **发射监管** | `不监管` / `5 / 15 / … / 95` 分钟（默认 **10**）；从开总开关（或人工操作）起连续发射超过该时长，**自动关闭发送总开关** |
| **无回应次数（换台阈值）** | `0`（忽略，默认）… `30`；对方连续无回应达到该次数后**放弃当前目标**：优先换到别的 CQ 台，没有就自己发 CQ |
| **自动收录 CQ 台（本波段）** | 每解到一个**本波段还没通联过**的 CQ 台就自动加入 ⭐ 关注列表（默认开；跨波段通联过的台在本波段仍会收录）；同时把 CQ 台纳入自动候选。关掉后**只**自动呼叫「关注名单」里 CQ 台的 CQ |
| **自动呼叫 CQ 台** | 是否**真的去呼叫**候选里的 CQ 台（默认开，**总闸**）；关掉就只自己发 CQ、只回应定向呼叫 |

> **无回应按「解码批次」计数**，不要求每批都发过；收到有效回复即清零。
> `0`＝忽略意味着对同一目标一直重发（FT8CN 默认），此时靠「发射监管」兜底防止无限发射。

### 11.3 人工操作不暂停自动程序

FT8CN 没有「手动接管 / 暂停」概念：你手动设目标、发 CQ 或逐条发送，只是把**发射指令**改掉，
自动程序下一批解码照旧运行（并复位「发射监管」计时）。要彻底停自动发射，请关「发送总开关」。

## 13. 日志页与 ADIF

### 13.1 浏览与筛选

- 顶部「共 n 条」+ **搜索**（呼号 / 网格）。
- 筛选 Chip：**波段** / **模式**（FT8·FT4）/ **日期范围（UTC）**；有筛选时出现「清除」。
- 卡片：呼号（已确认时带 ✔ 与绿色色条）· 网格 · 波段 + 模式 · UTC 时间 · `收 x / 发 x` 报告。
- 底部常驻统计：`QSO / DXCC / 网格 / 确认` + 波段柱图。
- **单击卡片＝编辑**；**长按＝菜单**（编辑 / 删除）。
- 自动落库的记录会同时保存**起始时间**与**完成时间**（照 FT8CN 的 `startTime`）：列表显示完成时间，导出 ADIF 时分别写到 `TIME_ON` 与 `TIME_OFF`。

### 13.2 新增 / 编辑 / 删除

- 右上 **⋮** → `新增通联`：手填呼号 *（必填）*、网格、UTC 日期 / 时间、波段、模式、双方报告、QSL / LoTW 确认、备注。
- **删除单条需二次确认**（也会先提示不可撤销）。
- ⋮ → `清空日志`：删除全部（**二次确认**，建议先导出 ADIF）。

### 13.3 ADIF 导入 / 导出

- 入口：日志页 ⋮，或设置 → 日志。通过系统文件选择器（SAF），**不需要存储权限**。
- **导入为合并**：确认 `Y` 具粘性、非空字段优先、时间容差 ±60 s；不会覆盖已有记录的确认状态。
- 导出会写出 `QSO_DATE` / `TIME_ON`（起始）与 `QSO_DATE_OFF` / `TIME_OFF`（完成）；导入时若缺 `TIME_OFF` 则与 `TIME_ON` 相同（兼容只有单时间的日志）。

### 13.4 备注

自动写入的备注形如：

```
Distance: 1234 km, Qso by Ft8Vox
```

（可在编辑框里继续补充。）

## 15. 后台运行与返回键

- 接收由**前台服务**保活：切到后台、息屏都会**继续接收**；用系统文件选择器（SAF）也不再中断。
- **接收中按返回键**：退到后台继续接收（弹短提示）；要停止用通知栏的「停止接收」。
- **未接收时按返回键**：正常退出。
- 抽屉 / 详情弹窗打开时，返回键**先收起它们**。
- Android 13+ 若拒绝了通知权限，前台服务通知不可见（接收仍运行），需到系统设置里开启。

## 16. 常见问题与排错

| 现象 | 排查 |
| --- | --- |
| **解码列表一直空** | 是否已开始接收？麦克风权限是否给了？输入设备 / 输入增益是否合适（电平 −30 ~ −10 dB）？电台音量是否够？确认选择的波段与频率上有信号 |
| **「请至少开启一个筛选」** | 筛选条至少选一个 Chip（或点「全部」） |
| **瀑布不动** | 未开始接收（空态点一下）；或输入设备选错 |
| **解出的 SNR 偏低 / 整片亮** | 输入过载削顶：减小电台音量 / 输入增益，或换声学耦合距离 |
| **时间不同步（红字）** | 手机时间不准：打开网络自动对时；仍偏则用「时隙偏移」微调（见 §10） |
| **点了「发送」但没发** | 发送总开关是否打开？是否在我方发射周期（顶栏 `TX：n` 高亮）？本时隙剩余时间不够时是**排到下一个周期**，不是丢 |
| **发射没声音 / 电台不键控** | 输出声卡选择、输出音量（是否被调到很低）、电台 VOX 灵敏度 / 输入电平；先用「测试音」联调；必要时开「发射前导音」并加长「前导音时长」 |
| **输出声卡「无响应」** | 输出被系统挂起时的提示；重试即可（已做坏流自愈）。仍不行则重新「开始接收」或重进 App |
| **USB 声卡没出现** | 重进设置页刷新；确认 OTG 线与声卡供电 |
| **本机也能解出自己发的报文** | 正常现象（自听）。这类报文只显示、不参与 QSO 路由 |
| **两台机器互测一直重复报告** | 已修复（标准语义：收到 `R<报告>` 直接回 `RR73`）；若仍复现请附截图与时间段 |

## 17. 已知限制

- **不做 CAT**：无法控制 / 读取电台频率、模式、PTT，也无法感知 VOX 键控是否成功。
- 不做 Hound / Fox（DXpedition）、标准序列之外的变体（`TU;` 等）、竞赛报文。
- 不做 FST4（`ft8_lib` 仅含 FT8 / FT4）；模式菜单仅 FT8 / FT4。
- 不做在线地图瓦片（离线栅格卫星底图已实装）、在线日志上传（CloudLog / LoTW / eQSL）、局域网后台、瀑布配色。
- DXCC / ITU / CQ 区域按**呼号前缀映射实体表**（不是逐条精确判定）。
- 音频设备 id 可能随插拔 / 重启变化，失配时回退系统默认。
- 地图纵向循环越过 ±85° 后接另一侧极区，会有一次纬度跳变（墨卡托在极点发散，无法避免）。
- **发射时不静音接收**；声学耦合下建议注意音量以避免自激。
- 模拟器无音频输入：地图实时标记 / 连线与解码列表通常为空（发射可用）。

### 19.4 原生库

- 原生代码位于 `app/src/main/cpp/`，由 CMake 构建为共享库 `libft8.so`（DSP 复用 `ft8_lib` 的 `monitor.c` + kissfft）。
- 上游 `app/src/main/cpp/ft8_lib/` 视为第三方，**尽量不修改**；定制逻辑放在 `jni_bridge.c` 与 `audio_engine.c` 及 Kotlin 层。
- 编入 `jni_bridge.c`、`ft8_lib/common/`（monitor/wave）与 `ft8_lib/fft/`（kissfft）；**排除 `ft8_lib/common/audio.c`**（依赖 PortAudio，Android 无法编译）。
