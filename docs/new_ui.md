# FT8VOX · 安卓端 UI 设计（单操作页风格）

## 0. 全局安卓规范

* 深色主题：背景 `#12121A`，卡片 `#1E1E2E`，文字 `#CDD6F4`，强调蓝 `#89B4FA`
* 字体：呼号 16sp 粗体，消息 13sp，辅助信息 11sp
* 触摸目标 ≥ 48dp
* 底部导航 4 项：操作 / 地图 / 日志 / 设置
* 顶部 AppBar 固定：UTC 时间、频率、RX/TX 点（第 2 行追加时隙号 `RX：n` / `TX：n`；第 3 行显示待发/发射中报文，仅我方发射时隙出现）
* 底部再放一条「状态条」：VOX 电平、解码数、QSO 数、TX 倒计时

---

## 1. 顶部 AppBar（56dp）

左：菜单图标（打开频段/模式/帮助）

中：

* 第 1 行（大）：`14:32:17 UTC`
* 第 2 行（小）：`14.074.000 MHz · FT8 · RX：1` —— 时隙用 **0/1** 号（不用奇/偶）：
  接收时隙为 `RX：n`、我方发射时隙为 `TX：n`（n = 0/1）；TX 号取当前锁定的发射周期 `txParity`，
  RX 号取当前时隙 `slotParity`；TX 段用强调蓝。
* 第 3 行（小，**仅我方发射时隙、且有报文或正在发射时出现**）：`待发 CQ DX0ABC`（强调蓝）
  或 `发射中 CQ DX0ABC`（红）。没有报文时该行不显示；三行都用紧凑行高，顶栏高度仍为 56dp。
* 关闭发送总开关或未开始接收时，第 2/3 行的时隙段整段不显示；过长时省略号截断。
  右：
* 圆点：绿=RX，红=TX 脉动
* 小喇叭图标：点开音频/VOX 速览

## 3. 操作页（主屏，唯一核心页）

竖向布局（手机竖屏）：

```
AppBar
──────────────
瀑布图 30%
──────────────
筛选 Chip 行
──────────────
解码消息列表（可滚动，占剩余大部分）
──────────────
发射控制
──────────────
底部状态条
底部导航
```

### 3.1 瀑布图区（屏幕高度约 30%）

* 全宽，高度约 `0.30 * 屏高`
* 横轴 0–3000 Hz，纵轴时间向下滚
* 归一化自动配色：
  * 0–0.25 深蓝
  * 0.25–0.5 青
  * 0.5–0.75 绿→黄
  * 0.75–1.0 橙→红
* 右侧小字：`Ref -50~-10dB`
* 交互：
  * 单击信号条 → 设发射频点
  * 长按信号条 → 弹菜单：呼叫 / 看详情 / 忽略
  * ~~双指捏合 → 缩放频率~~（已去掉：频率轴固定铺满 `fMin–fMax`，不做缩放/平移）
* 顶部浮条：增益、噪抑、带宽、暂停（小图标）

---

### 3.2 筛选 Chip 行（横向滚动）

不是按钮组，是 **Material Chip**，按下/弹起：

* 全部
* 与我有关
* CQ
* 回复
* 73
* 已通联

行为：

* 「全部」按下 → 其他自动取消
* 其他可多选：比如 CQ + 与我有关 同时亮
* 都没选 → 列表显示空状态：「请至少开启一个筛选」
* 每个 Chip 右侧小角标：`CQ 23`
* 选中 Chip：蓝底白字；未选：深灰底浅字

---

### 3.3 解码消息列表（核心，占最大面积）

每张卡片（RecyclerView Item）：

```
[色条] JA1ABC   PM95   -12dB    14:32:05
```

左侧色条含义：

* 绿：新解码
* 蓝：与我有关
* 橙：CQ
* 灰：重复
* 粉：新呼号
* 棕：新 DXCC / 新 ITU
* 紫：新网格
* 红线/删除线：已通联过
* 黄底黑字：正在发射
* 呼号里包含“我”：红字

卡片交互（手机手势）：

* **左滑**：呼叫该台（露绿色「呼叫」条）
* **右滑**：忽略该呼号
* **单击**：底部弹 Half-sheet 详情（距离、方位、网格、强度曲线、按钮：呼叫 / 日志 / 备注）
* **双击**：跳地图页定位
* **长按**：菜单（复制消息 / 加宏 / 忽略）

列表空状态：

* 没解码：「等待解码…」
* 筛选项为空：「没有符合条件的解码消息」

### 3.4 发射控制区（底部上拉抽屉）

手机不能右边再放一列，改成：

#### 收起态（默认）

一条 56dp 条：

* 左：目标 `→ JA1ABC`
* 中：当前消息类型 `回复`
* 右：~~大按钮「发送」~~ → **「发送总开关」Switch**（U8 起收起态只保留这一个控制；U9 补记 4 定稿为**纯权限**：关 = 只接收，开 = 允许发射，**开关本身不发任何报文**。大按钮「发送」在展开面板内，见下。）

#### 上拉展开（Bottom Sheet）

内容：

1. 目标信息：呼号 / 网格 / 频率 / 「取消目标」
2. 消息类型大按钮（2 行）：
   * CQ / 回复
   * 交换 / RR73 / 73
3. 自定义文本输入框：
   * 标签「自定义」
   * 字符计数 `42/75`
   * 清除 X
4. 宏按钮：4×2 网格（可编辑）
5. 发送队列：横向胶囊
   * `1:JA1ABC/回复`
   * 点开可删除/拖序
   * 「清空」
6. 大发射按钮（48dp+）：
   * 显示待发摘要
   * 点按：本周期剩 >2.5s 立即发，否则排下一周期
   * TX 时变红 + 倒计时

## 4. 地图页

### 4.1 布局

全屏深色底图，无网格线图层。底部浮层显示图例和统计。右下角浮控：缩放、回我的位置。

### 4.2 网格标记

- **蓝色**：该网格内有被解码到的信号。每次软件重启自动清除。
- **黄色**：与该网格的电台完成了一次 QSO。（读取日志  完成的qso显示到地图上）
- **红色**：该 QSO 的确认信息已收到（如 LoTW/eQSL 确认）。（读取日志  完成的qso显示到地图上）

无信号时不叠加任何标记，整块网格保持空白。

### 4.3 呼号标记

- 信号里**没有网格信息**时：用呼号前缀对应的归属地坐标，在那里立一个标。
- 呼号标记同样按颜色规则显示：蓝=收到信号，黄=完成QSO，红=已确认。

### 4.4 CQ 旗帜

- 解码到 **CQ 信息**时，在该位置立一面**红色旗帜**，一眼看出谁在呼叫 CQ。
- 可以设置是否带呼号和信号强度

### 4.5 信号连线

在各方之间拉直线，线上有内容沿对应方向运动：

- **信号报告**（如 `-12` / `+03`）：直接在线上显示数字，按通信方向从一方跑向另一方。
- **73 / RR73**：显示「73」或「RR73」文字，不显示符号/箭头。
- 内容开关：可以整体关闭文字，简化为**一个移动的方块**沿线运动，只表示"有信息在传输"。
- 只显示上一时隙的信号连线

## 6. 设置页（安卓 Preference 风格）

分组：

### 6.1 电台（仅 VOX）

* VOX 触发：音频检测 / 静音检测
* VOX 延迟 50–1000 ms
* VOX 阈值 -60 \~ -20 dB
* 发射前导音 开关 + 时长
* 输出声卡选择
* 测试音按钮 + 电平条
* PTT 延迟、看门狗

### 6.2 音频

* 输入/输出设备
* 采样率 44100/48000/96000
* 输入增益

### 6.3 FT8

* 模式 FT8/FT4（FST4 不做：`ft8_lib` 无该模式，见 `NEW-UI-PLAN.md`）
* 发射偏移 0–15s
* 解码深度 （max_candidates ldpc_iterations rx_time_osr rx_freq_osr 都可以设置）
* 自动序列参数

### 6.4 高亮与提醒

复选：

* 新 CQ 区域
* 新 ITU
* 新 DXCC
* 新网格
* 新前缀
* 新呼号
* 已通联（删除线/下划线/隐藏）
* 含我呼号哔声
* 末端标记：红=有我，蓝=正通联

### 6.5 外观

* 暗/亮
* 字体小/中/大
* ~~瀑布图配色~~（已删除：native 渐变固定，不做配色切换，见 `NEW-UI-PLAN.md` §收尾）
* 恢复布局（瀑布高度 / 字体）

### 6.6 日志

* ADIF 路径（导入 / 导出）
* 清空全部记录
* ~~CloudLog / LoTW / eQSL~~（已删除：不做日志上传，见 `NEW-UI-PLAN.md` §收尾）
* ~~局域网后台开关~~（已删除：不做局域网后台，同上）
