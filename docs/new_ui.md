# FT8VOX · 安卓端 UI 设计（单操作页风格）

## 0. 全局安卓规范

* 深色主题：背景 `#12121A`，卡片 `#1E1E2E`，文字 `#CDD6F4`，强调蓝 `#89B4FA`
* 字体：呼号 16sp 粗体，消息 13sp，辅助信息 11sp
* 触摸目标 ≥ 48dp
* 底部导航 4 项：操作 / 地图 / 日志 / 设置
* 顶部 AppBar 固定：UTC 时间、频率、TX 点（第 2 行追加**我方发射时隙号** `TX：n`，n = 0/1；第 3 行显示待发/发射中报文，仅我方发射时隙出现）
* 底部再放一条「状态条」：输入电平、解码数、QSO 数、TX 倒计时

## 1. 顶部 AppBar（56dp）

左：菜单图标（打开频段/模式/自动程序/设置）

* 菜单里的「模式」一行列出 FT8 / FT4（当前项带 `●`）。**协议不能热切换**（时隙长度与调制
  方式在 native 引擎创建时固定），所以**运行中切换会自动重建引擎**（内部 `stop()` + `start()`，
  接收短暂中断；发送总开关状态保留、当前 QSO 结束）；未接收时下次开始接收生效。

中：

* 第 1 行（大）：`14:32:17 UTC`
* 第 2 行（小）：`14.074.000 MHz · FT8 · TX：1` —— 只显示**我方发射时隙号**（**0/1** 号，不用奇/偶），
  取当前锁定的发射周期 `txParity`；**不再显示接收时隙号**（接收时隙号对操作无指导意义）。
  处于我方发射时隙时该段用强调蓝（发射中为红），接收时隙保持弱化色。
* 第 3 行（小，**仅我方发射时隙、且有报文或正在发射时出现**）：`待发 CQ DX0ABC`（强调蓝）
  或 `发射中 CQ DX0ABC`（红）。没有报文时该行不显示；三行都用紧凑行高，顶栏高度仍为 56dp。
* 未开始接收时第 2/3 行的时隙段整段不显示（关闭发送总开关时仍显示 `TX：n` —— 只表示发射周期，
  与是否允许发射无关；未开始接收时才整段隐藏）；过长时省略号截断。
  右：
* 圆点：绿=RX，红=TX 脉动
* 小喇叭图标：点开音频/VOX 速览

## 3. 操作页（主屏，唯一核心页）

竖向布局（手机竖屏）：

```
AppBar
──────────────
瀑布图 30%
──────────────
筛选 Chip 行
──────────────
解码消息列表（可滚动，占剩余大部分）
──────────────
发射控制
──────────────
底部状态条
底部导航
```

### 3.1 瀑布图区（屏幕高度约 30%）

* 全宽，高度约 `0.30 * 屏高`
* 横轴 0–3000 Hz，纵轴时间向下滚
* 归一化自动配色：
  * 0–0.25 深蓝
  * 0.25–0.5 青
  * 0.5–0.75 绿→黄
  * 0.75–1.0 橙→红
* 右侧小字：`Ref -50~-10dB`
* 交互：
  * 单击信号条 → 设发射频点
  * 长按信号条 → 弹菜单：呼叫 / 看详情 / 忽略
  * ~~双指捏合 → 缩放频率~~（已去掉：频率轴固定铺满 `fMin–fMax`，不做缩放/平移）
* 顶部浮条：增益、噪抑、带宽、暂停（小图标）

---

### 3.2 筛选 Chip 行（横向滚动）

不是按钮组，是 **Material Chip**，按下/弹起：

* 全部
* 与我有关
* CQ
* 回复
* 73
* 已通联

行为：

* 「全部」按下 → 其他自动取消
* 其他可多选：比如 CQ + 与我有关 同时亮
* 都没选 → 列表显示空状态：「请至少开启一个筛选」
* 每个 Chip 右侧小角标：`CQ 23`
* 选中 Chip：蓝底白字；未选：深灰底浅字
* 最左侧**固定**一个「清除解码信息」按钮（垃圾桶图标，不随 Chip 横滚）：一键清空本会话的解码列表；
  列表为空时置灰不可点。它只清**显示**列表 —— 不写日志、不改「已解码时隙」计数、不影响自动程序。

---

### 3.3 解码消息列表（核心，占最大面积）

**排序与自动翻页**：列表**新→旧**（最新一条在最上面，最多保留 200 条）。每批新解码到达时列表**自动翻到最新**；
用户手动拖动翻看历史时暂停跟随（不清屏、不打断阅读），把列表滑回顶部后自动恢复跟随。

每张卡片（RecyclerView Item）：

```
[色条] JA1ABC   PM95   -12dB    14:32:05
```

左侧色条含义：

* 绿：新解码
* 蓝：与我有关
* 橙：CQ
* 灰：重复
* 粉：新呼号
* 棕：新 DXCC / 新 ITU
* 紫：新网格
* 红线/删除线：已通联过
* 黄底黑字：正在发射
* 呼号里包含“我”：红字

卡片交互（手机手势）：

* **左滑**：**设为目标并呼叫**该台（露绿色「呼叫」条）—— 直接把红线移到该条频率、把发射时隙对到对方时隙的相反周期并交给第 3 层接管；**没有任何确认框**，唯一闸门是「发送总开关」。本时隙来得及就本时隙发（见 §3.4 第 6 条）
* **右滑**：忽略该呼号
* **单击**：底部弹 Half-sheet 详情（距离、方位、网格、强度曲线、按钮：呼叫 / 日志 / 备注）
* **双击**：跳地图页定位
* **长按**：菜单（复制消息 / 加宏 / 忽略）

列表空状态：

* 没解码：「等待解码…」
* 筛选项为空：「没有符合条件的解码消息」

### 3.4 发射控制区（底部上拉抽屉）

手机不能右边再放一列，改成：

#### 收起态（默认）

一条 56dp 条：

* 左：目标 `→ JA1ABC`
* 中：当前消息类型 `回复`
* 右：~~大按钮「发送」~~ → **「发送总开关」Switch**（U8 起收起态只保留这一个控制；U9 补记 4 定稿为**纯权限**：关 = 只接收，开 = 允许发射，**开关本身不发任何报文**。大按钮「发送」在展开面板内，见下。）

#### 上拉展开（Bottom Sheet）

内容：

1. 目标信息：呼号 / 网格 / 频率 / 「取消目标」
2. 消息类型大按钮（2 行）：
   * CQ / 回复
   * 交换 / RR73 / 73
3. 自定义文本输入框：
   * 标签「自定义」
   * 字符计数 `42/75`
   * 清除 X
4. 宏按钮：4×2 网格（可编辑）
5. 发送队列：横向胶囊
   * `1:JA1ABC/回复`
   * 点开可删除/拖序
   * 「清空」
6. 大发射按钮（48dp+）：
   * 显示待发摘要
   * 点按：**本时隙剩余时间够播完整条报文（报文时长 + 前导）就立即发**，否则排下一个我方周期
     （FT8 报文 12.64s / 时隙 15s、FT4 报文 4.48s / 时隙 7.5s，所以本时隙开头约 2s 都还来得及）
   * TX 时变红 + 倒计时

> **发射闸门（定稿）**：全 App **不再有任何「确认发射」弹窗** —— CQ / 应答 / 解码卡片左滑 /
> 详情面板「呼叫」/ 地图页呼号标记「应答」/ 抽屉「发送」**都是点下即排程**（顶栏第 3 行随即出现
> 待发 / 发射中）。唯一闸门是**「发送总开关」**（关 = 只接收，开 = 允许发射），另有常驻的
> 「停止发射」与紧急中止。**仅存**的一处确认是「启用自动程序」（模式 0 → 1/2，因为它会自动打开
> 总开关并开启无人值守发射）。

## 4. 地图页

### 4.1 布局

全屏深色底图，无网格线图层。底图是**离线 Web Mercator 卫星影像**（`assets/map/world_z5.jpg`，8192×8192，z5；按可见区域流式解码并乘 0.7 暗化，资产缺失时退回纯色矩形），因此投影由等距圆柱改为 **Web Mercator**（`MapProjection`）。底部浮层显示图例和统计。右下角浮控：缩放、回我的位置。

### 4.2 网格标记

- **蓝色**：该网格内有被解码到的信号。每次软件重启自动清除。
- **黄色**：与该网格的电台完成了一次 QSO。（读取日志  完成的qso显示到地图上）
- **红色**：该 QSO 的确认信息已收到（如 LoTW/eQSL 确认）。（读取日志  完成的qso显示到地图上）

无信号时不叠加任何标记，整块网格保持空白。

### 4.3 呼号标记

- 信号里**没有网格信息**时：用呼号前缀对应的归属地坐标，在那里立一个标。
- 呼号标记同样按颜色规则显示：蓝=收到信号，黄=完成QSO，红=已确认。

### 4.4 CQ 旗帜

- 解码到 **CQ 信息**时，在该位置立一面**红色旗帜**，一眼看出谁在呼叫 CQ。
- 可以设置是否带呼号和信号强度

### 4.5 信号连线

在各方之间拉直线，线上有内容沿对应方向运动：

- **信号报告**（如 `-12` / `+03`）：直接在线上显示数字，按通信方向从一方跑向另一方。
- **73 / RR73**：显示「73」或「RR73」文字，不显示符号/箭头。
- 内容开关：可以整体关闭文字，简化为**一个移动的方块**沿线运动，只表示"有信息在传输"。
- 只显示上一时隙的信号连线
- **CQ 不连线**：CQ 报文只有发方、没有收方（对端位置用红旗表示，见 §4.4），所以不拉线；
  连线只画收发双方都在的报文（如 `A B -12`），避免一堆线全汇到「我」身上。

## 6. 设置页（安卓 Preference 风格）

分组：

### 6.1 电台（仅 VOX）

* 发射前导音 开关 + 时长
* 输出声卡选择
* 输出音量 −30\~0 dB（**只能衰减**：发射波形本身已是数字满幅，0 dB = 原样输出；
  对报文与「测试音」都生效，热生效）
* 测试音按钮 + **输入电平条**（纯显示：观察输入/校准「输入增益」，不做任何判定）
* PTT 延迟、看门狗

> **已删除**（2026-09-26）：原「VOX 触发（音频检测/静音检测）、VOX 延迟、VOX 阈值」三项及其
> 「触发/空闲」状态指示。那是一套「无 CAT 时用输入电平近似信道活动」的纯显示概念，FT8CN 没有，
> 也**不参与发射门控**，徒增误解，按用户要求整体移除。native 现只保留**输入电平读数**（底栏
> `电平 -xx dB` / 顶栏「音频」速览 / 6.1 电平条），`voxLevelDb` 不参与任何判定。

### 6.2 音频

* 输入/输出设备
* 采样率 44100/48000/96000
* 输入增益 −12\~+30 dB（采集链路，含输入电平读数）

### 6.3 FT8

* 模式 FT8/FT4（FST4 不做：`ft8_lib` 无该模式，见 `NEW-UI-PLAN.md`）。**运行中改协议会自动
  重建引擎**（接收短暂中断）—— 见 §1 顶栏「模式」；FT8 时隙 15 s、FT4 7.5 s
* 时隙偏移 −2.5s–+2.5s（步进 100ms，显示带正负号）：**整个时隙一起偏移**（解码窗口 +
  发射起点），用于校准本机时钟/声卡时延。用法写在设置项副标题里：把操作页解码卡片显示
  的「时间差 DT」原样填进来（如 +1.5s → +1500 ms），校到 DT 约 0 即可；正值=推后、负值=提前
* 解码深度：预设「快 / 标准 / 深」一键改下面 6 项（时间 OSR、频率 OSR、最低得分、LDPC 迭代、
  候选上限、单时隙上限），**频率范围不随预设变化**；单项手改后预设变「自定义」。
  每项在设置页都带一行作用说明：
  * **时间 OSR**（1–4，默认 2）每符号在时间上的细分数 → DT 时间分辨率 / 弱信号同步；*需重开接收生效*
  * **频率 OSR**（1–4，默认 2）每 6.25 Hz 频率格的细分数 → DF 频率估计精度 / 邻近信号分辨；*需重开接收生效*
  * **最低得分**（4–40，默认 10）Costas 同步候选门限 → 调高更快但漏弱台
  * **LDPC 迭代**（5–60，默认 25）纠错码最大迭代次数 → 调高弱信号解码率、更慢
  * **候选上限**（20–500，默认 140）单时隙保留的同步候选数 → 调高给弱台更多机会、更慢
  * **单时隙上限**（5–100，默认 50）单时隙最多输出的报文数 → 拥挤波段调大避免丢弃
  * **频率下限 / 上限**（默认 200 / 3000 Hz）解码搜索与瀑布显示范围 → 越窄越快；*需重开接收生效*
* 自动序列参数
