# Ft8Vox · JTDX 风格界面改造设计（横屏）

> 本文是「模仿 JTDX 界面 + 频谱单开一页 + 六个发射报文槽」这一轮改造的准绳。
> 它**取代** `docs/UI.md` 中「顶栏 + 底部四页导航 + 发射抽屉」那一套外壳描述；
> `docs/UI.md` 里的配色板、语义色、解码逻辑、JNI 契约、路线图仍然有效。
>
> 决策来源：2026-09-29 与用户的四轮问答，结论见 §1。

---

## 1. 已确认的决策

| 决策点 | 结论 |
| --- | --- |
| 页面形态 | **强制横屏**（`sensorLandscape`），贴近 JTDX 桌面横版 |
| 配色 | **保留现有深色板**（`docs/UI.md` §1.1），只借用 JTDX 的「方块控件 + 绿色高亮 + 面板分割」形态 |
| 导航 | **屏幕最左侧竖向窄导航栏**，5 项：操作 / 频谱 / 地图 / 日志 / 设置 |
| 频谱 | **单开一页**，整页瀑布 + 频率刻度 + 发射频率（单击/长按设频手势保留） |
| 解码列表 | **紧凑表格**：时隙 / UTC / 分贝 / 时差 / 频率 / 信息 |
| 操作页分栏 | **信息头 + 左表格 + 右控制列 + 底发射区** |
| 六个报文槽 | **Tx1–Tx6 直接映射现有六步报文**（网格 / 报告 / R报告 / RR73 / 73 / CQ），**点击 = 立即排程发射**（`sendOnce`；CQ 槽走 `startCq`） |
| 缺失控件 | JTDX 有、本项目没有对应实现的（猎犬 / 渴望 / Spt / AGC补偿 / 窄频 / 记录通联 / 时差修正 / 清除DX / 调谐 / 单次通联 / 回答B4 / 功率表 / DX远征 / 语言）**一概不出现** |
| 菜单栏 | **做**，作为快捷入口：文件 / 显示 / 模式 / 解码 / 自动程序 / 设置 / 帮助（只放有效项） |
| 控制行 | **做**，只保留有对应功能的：波段 / 报告 / DX 呼号 / DX 网格 / 带宽 / 时差 / 同频异频 |
| 筛选 | 收进「过滤」按钮弹窗，表格上方**只留一行** |
| 关注列表 / 自动程序 | 都是 **JTDX 式居中对话框** |
| 底发射区 | `生成信息` + 自定义输入框 + CQ 前缀下拉 + 六个报文槽 + 发送总开关 |
| 推进节奏 | 一次性改完再整体验收 |

- 底部状态条 **26dp**。

## 3. 控件映射（JTDX → 本项目）

| JTDX | 本项目实现 |
| --- | --- |
| 大频率 `14.074.000` | `status.dialHz`（`BandPlan` 解析的刻度频率），辅助行显示 `MHz · 波段` |
| 大时钟 `11:19:01` | `QsoTime.isoTime(nowMs)`，辅助行 `UTC` |
| `TX 15/45` | `TX {时隙内已过秒}/{时隙长秒}`，由 `slotProgress × slotMs` 换算 |
| 功率表竖条 | 输入电平 `status.voxLevelDb`（−60…0 dB 映射），绿→黄→红 |
| 波段下拉 | `BandPlan.bands` + `setBandFreq` |
| `报告 -15` | `qso.reportSent`，无则 `TxCompose.reportFor(messages, 目标)` |
| `DX 呼号` / `DX 网格` | **可手动输入**；点选解码行会自动回填（用户改过就不覆盖）；旁边的「呼叫」按钮调 `answer(call, grid)` 发起应答 |
| `带宽 100%` | 解码频率范围 `decode.fMinHz–fMaxHz`（点击进设置页） |
| `时差 0.0 秒` | `slotOffsetMs`（点击进设置页） |
| `Tx=Rx 异频` | `sameFreqTx` 开关（同频 / 异频发射） |
| `生成信息` | 把当前状态下「该发的那条报文」填入自定义框；无目标时填 CQ |
| `CQ` 勾选 | CQ 前缀下拉（`cqPrefixes` / `cqPrefixIndex`） |
| `发射 1`…`发射 6` | 六步报文槽（§4），点击即排程 |
| `接收信息` 行 | 自定义/待发报文的实时预览 |
| 右列 `监听` | 开始 / 停止接收 |
| 右列 `停止` | 停止发射（`stopTransmit`） |
| 菜单栏各项 | 见 §5 |

**不出现**：调谐、绕过过滤、单次通联、回答B4、猎犬、渴望、Spt、AGC补偿、窄频、记录通联、时差修正、清除DX、DX远征、语言、功率表文字标签。

## 4. 六个发射报文槽

槽内容**不持久化**，每帧由 `TxCompose.compose` 用当前状态算出来，因此永远与六步序列一致：

| 槽 | `TxMessageKind` | 报文形态 | 点击行为 |
| --- | --- | --- | --- |
| Tx1 | `GRID` | `目标 我 网格` | `sendOnce` |
| Tx2 | `REPORT` | `目标 我 报告` | `sendOnce` |
| Tx3 | `ROGER` | `目标 我 R报告` | `sendOnce` |
| Tx4 | `RR73` | `目标 我 RR73` | `sendOnce` |
| Tx5 | `SEVENTY_THREE` | `目标 我 73` | `sendOnce` |
| Tx6 | `CQ` | `CQ <前缀> 我 网格` | `startCq` |

- `报告` 取值优先级：`qso.reportSent` → `TxCompose.reportFor(messages, 目标)` → `0`。
- `R 报告` 取 `qso.reportReceived`（对方给我的报告），无则退回上面的值。
- 目标为空时 Tx1–Tx5 置灰不可点（无法组报文）。
- 指示灯：该槽报文 == `status.displayTxText` 时点亮（发射中为红、待发为绿）。
- 发射闸门仍是**发送总开关**（`txEnabled`，默认关）；总开关关闭时点击会被 `SessionViewModel` 拦下并给出提示，不会误发。

## 6. 交互约定（本轮改动后）

| 操作 | 行为 |
| --- | --- |
| 解码表格**单击** | 设为目标 + 对频（同频发射时移动红线），并在控制行显示 DX 呼号/网格 |
| 解码表格**双击** | 跳地图页并定位该呼号 |
| 解码表格**长按** | 菜单：呼叫 / 回复 / 详情… / 查看日志 / 复制消息 / 关注·取消关注 / 忽略 |
| 解码表格**左滑 / 右滑** | 左滑 = 设为目标并呼叫；右滑 = 删除该条 |
| 频谱页瀑布**单击 / 水平拖动** | 设发射频率（红线 = 报文下边频） |
| 频谱页瀑布**长按** | 先把红线移到按下处，再打开最近一条解码的详情 |
| 过滤按钮 | 打开筛选弹窗（六个 Chip + 呼号/前缀/网格搜索） |
| 控制行「呼叫」 | 用 `DX 呼号` / `DX 网格` 里当前的内容发起应答（闸门仍是发送总开关） |
| 关注列表按钮 | 打开 JTDX 式对话框（左滑呼叫 / 右滑取消关注） |
| 自动程序按钮 | 打开 JTDX 式对话框（四项策略） |
| 返回键 | 接收中退到后台继续接收；弹窗打开时先关弹窗 |

**移除**：发射抽屉的「跟手拖动」交互、解码详情从底部升起的 ModalBottomSheet、底部四页导航栏。
（抽屉改为**常驻底发射区**，详情改为**居中对话框**。）
