# Ft8Vox 阶段 7e 真机回归清单

> 适用版本：阶段 7（7a/7b/7c/7d 已落地）
> 更新日期：2026-09-25
> 上游文档：`docs/ROADMAP.md`（阶段 7 验收）、`docs/UI-DESIGN.md`（§0 状态表、§5 各页规格）

## 0. 目的与范围

阶段 7 的**离线部分**（设置项接入、空态/错误态、纯逻辑单测）已由 7a–7d 与 7e 的代码改动覆盖。
剩下唯一无法由开发机代办的是**真机全流程回归**，其验收标准为：

> 真机与 WSJT-X / FT8CN 完成一次通联并**自动落库**；导出 ADIF 可被常见日志软件导入；
> 解码参数改动生效；过滤与 Call 1st 行为符合预期；已通联网格正确点亮；**网格页能实时显示当前接收的台站与信号**。

本清单把验收拆成可勾选步骤，供在真机上逐项执行。

## 1. 前置准备

| 项 | 要求 |
| --- | --- |
| 设备 | Android 真机（本项目在 vivo V2338A / `10CE5Z1GSZ001TM` 上验证过 USB 调试） |
| 权限 | 开发者选项已开启「USB 调试（安全设置）」与「通过 USB 安装应用」 |
| 音频 | 声学耦合（手机麦克风 ↔ 电台扬声器、手机扬声器 ↔ 电台麦克风）或 USB 声卡/OTG 线缆 |
| 对端 | 另一台运行 WSJT-X 或 FT8CN 的电台，或监听同一波段的友台 |
| 工具 | `adb`（`C:\Users\wty\AppData\Local\Android\Sdk\platform-tools\adb.exe`），真机与模拟器同时在线时用 `-s <serial>` 指定 |
| 合法 | 确认发射功率/频率符合所在地区无线电管理法规，并对发射行为负责 |

安装本次构建：

```powershell
adb -s <serial> install -r app/build/outputs/apk/debug/app-debug.apk
```

> 提示：`connectedDebugAndroidTest` 会重装并清空 App 数据，回归前不要执行它，或在回归前重新填写台站信息。

## 2. 回归步骤

### A. 启动与设置（对应「设置项全部接入」）

- [ ] 首次启动进入「操作」页，呼号/网格未填时顶部报红提示「请到「设置」填写呼号与网格后再发射」。
- [ ] 设置 → 台站：呼号留空显示错误态与「发射前必须填写呼号」；填 `JA1ABC`（错误网格留空）正常。
- [ ] 网格填非法值（如 `ZZ99`）时显示「网格格式不正确」；填 `PM95` 后错误消失。
- [ ] 备注填 `QRP 5W`，说明文字提示「自动写入新通联记录的 COMMENT」。
- [ ] 发射：Hold Tx Freq 开关、**默认发射周期（偶/奇）**、Call 1st（关/最强 CQ/首个 CQ）、最大重试次数均可改并持久化。
- [ ] 解码：快/标准/深预设切换后各项数值正确；手动改任一项后出现「自定义」。
- [ ] 点「恢复默认（保留台站信息）」→ 呼号/网格/备注保留，其余回落默认（发射周期偶数、解码=标准等）。
- [ ] 界面：瀑布高度切「紧凑/标准/高」，回到操作页瀑布高度随之变化。
- [ ] 音频：采样率偏好（自动/48000/44100）下次「开始接收」生效，状态栏显示实际采样率。
- [ ] 杀进程重启：以上设置全部保留（DataStore 持久化）。
- [ ] 日志与 ADIF：显示「共 N 条记录」；清空需二次确认。

### B. 接收

- [ ] 点「开始接收」授予录音权限后，状态栏出现「接收中 / 时隙 N ms / 已解码时隙」并递增。
- [ ] 偶/奇周期行背景分色；时隙进度条推进；「丢帧」计数不持续快速增长。
- [ ] 有信号时解码列表出现报文（时间 / SNR / DT / DF / 文本）。
- [ ] 过滤：CQ only、「排除已通联」、呼号/前缀过滤即时生效；「显示 X / Y」正确。
- [ ] 高亮：发给我（亮蓝）、新网格（绿点）、新前缀（红点）、当前对手（琥珀）颜色符合设计。
- [ ] 点解码行 → 绿线（RX）移到该频率；Hold Tx 关时红线（TX）跟随，开时只动 RX。
- [ ] 解码列表无内容时显示空态文案（未开始接收 / 暂无解码 / 被过滤），三者可区分。

### C. 真实通联（**核心验收**）

- [ ] 与对端约定：同一波段、同一协议（FT8/FT4）、相对周期（我偶他奇或反之）。
- [ ] 展开控制面板，点「CQ」→ 确认弹窗显示呼号/频率/周期/协议 → 确认后按时隙发射 CQ。
- [ ] 对端应答后，我方自动按序列推进：收报告 → 发 `R+报告` → 收 `RR73`/`73` → 完成。
- [ ] 或反向：对端发 CQ，点其解码行「应答」→ 自动完成整段序列。
- [ ] 中途无回复时按「最大重试次数」重发；超过后放弃并回到空闲。
- [ ] 「停止发射」立即静音，状态回到空闲；再次开始可正常发射。
- [ ] 发射仅在我方周期时隙窗口内，其余时间静音（对端不应在非窗口时段听到信号）。

### D. QSO 自动落库（**端到端**）

- [ ] QSO 完成后操作页「最近通联」出现该条（呼号/网格/收发报告/波段）。
- [ ] 日志页「共 N 条记录」+1，列表出现该条，统计卡「通联 / 呼号 / 网格」同步。
- [ ] 该条记录：`MY_CALL`/`MY_GRID` 为记录时的快照；若设置里填了备注，`COMMENT` = 备注内容。
- [ ] 切到其它 Tab 再切回，记录仍在（已从内存态切到 Room）。
- [ ] 杀进程重启后记录仍在。

### E. Call 1st

- [ ] 设置 Call 1st = 「最强 CQ」或「首个 CQ」，回操作页点「启用」→ 弹出防误发确认（含呼号/频率/周期）。
- [ ] 确认后武装（显示 `Call 1st xxx●`）；每接收时隙末、QSO 空闲时自动挑一个符合条件的 CQ 应答。
- [ ] 一次 QSO 完成/失败后自动解除武装（`●` 消失）。
- [ ] 武装状态下点「关闭」可立即解除。

### F. 网格页实时台站（**核心验收**）

- [ ] 网格页：地图为 2:1 全球视图，「适应窗口」铺满；大/小网格粒度切换正确。
- [ ] 历史：日志里已有网格的格子按 已通联（绿）/已确认（蓝）着色；统计「已通联 / 已确认 / 大网格 x/324」与日志聚合一致。
- [ ] **实时**：接收中出现对端 CQ 后，「实时 N 台」> 0，地图上按网格中心出现斑点，颜色=高亮分类、半径/亮度随 SNR 变化。
- [ ] 「当前接收」列表出现呼号/SNR/DF/网格/时间，与操作页解码列表一致（最近 15 分钟内、同呼号取最近）。
- [ ] 点击实时点 → 详情面板（呼号/网格/SNR/DT/DF/时间）+「应答」「在日志中查看」；应答走确认弹窗。
- [ ] 点击空白网格 → 显示该网格历史通联；无记录时显示「该网格暂无通联记录」。
- [ ] 关闭「实时」开关后斑点与列表消失，仅剩历史底图。

### G. 解码参数（生效链路）

- [ ] 「深」预设下同样信号解码条数不少于「快」（可对同一段信号分别观察）。
- [ ] 接收中把「最低得分 / LDPC 迭代 / 候选上限 / 单时隙上限」任一项改动，无需重启即影响后续时隙（解码不中断）。
- [ ] 改「时间/频率 OSR」或频率上下限后，提示「需重启接收」；停止再开始后生效（状态栏频率轴范围随之变化）。

### H. ADIF 导入/导出

- [ ] 导出 ADIF：文件名 `ft8vox_YYYYMMDD.adi`（不被追加 `.txt`），内容含 `ADIF_VER` 头与各记录 `EOR`。
- [ ] 用常见日志软件（如 Log4OM / N1MM / WSJT-X 日志）导入该文件成功。
- [ ] 反向：从外部导出的 ADIF 导入本 App → 提示「新增 X / 跳过 Y」；同一文件再次导入全部跳过（判重口径：呼号+时间+波段+模式）。
- [ ] 中文备注导入导出往返不乱码（长度按 UTF-8 字节）。
- [ ] 已知限制：打开 SAF 选择器会使 App 进后台并停止接收（阶段 9 前台服务后消除）。

### I. 空态 / 错误态

- [ ] 日志页：无记录时「还没有通联记录」；有记录但筛选无结果时「没有符合筛选条件的记录」。
- [ ] 日志页：呼号未设置时提示「未设置呼号，导入的记录会缺少 MY_CALL」并可「去设置」。
- [ ] 操作页：未开始接收 / 暂无解码 / 被过滤三种空态文案正确。
- [ ] 网格页：无实时台站时「等待解码…」。
- [ ] 拒绝录音权限后开始接收 → 不崩溃，给出失败提示。

## 4. 模拟器可预演的部分

真机回归前可先在模拟器（`-s emulator-5554`）验证下列项，减少真机往返：

- 四个 Tab 切换不打断接收（「已解码时隙」持续增长）。
- 设置页所有控件（含本轮新增的瀑布高度、默认发射周期、恢复默认）写入与持久化。
- 呼号/网格错误态、三种空态文案。
- 防误发确认弹窗、Call 1st 武装/解除交互。
- 解码参数预设切换与运行中热更新（进程存活、状态仍「接收中」）。
- 网格页地图渲染、历史着色、粒度切换、点击选取与详情面板。
- ADIF 导出文件名与往返（导入两次的判重计数）。

> 模拟器无天线/音频输入，「实时 N 台」恒为 0，实时点绘制与命中已由 JVM 单测覆盖，须在真机确认。

## 5. 已知限制（本阶段不做）

- Hound/Fox（DXpedition）、标准序列之外的变体（`TU;` 等）、比赛报文。
- 在线地图瓦片、精确 DXCC 实体表、海岸线底图（`BaseMapLayer` 预留）。
- 输入/输出音频设备路由（当前用系统默认）。
- CAT 频率控制（无 CAT，波段由人工指定）。
- 打开 SAF 选择器会触发 `onStop` 停止接收。
- 发射时不静音接收。
