# Ft8Vox 真机回归清单

> 适用版本：阶段 7 + 新 UI（U1–U6 与 U7a/U7b/U7c/U7d 已落地；U7 其余能力逐项接后端后回填本文档的 `U7` 项）
> 更新日期：2026-09-25
> 上游文档：`docs/ROADMAP.md`（阶段 7 验收）、`docs/new_ui.md` + `docs/NEW-UI-PLAN.md`（新 UI）

## 0. 目的与范围

阶段 7 的**离线部分**（设置项接入、空态/错误态、纯逻辑单测）已由 7a–7d 与 7e 的代码改动覆盖。
剩下唯一无法由开发机代办的是**真机全流程回归**，其验收标准为：

> 真机与 WSJT-X / FT8CN 完成一次通联并**自动落库**；导出 ADIF 可被常见日志软件导入；
> 解码参数改动生效；过滤与自动程序行为符合预期；已通联网格正确点亮；**网格页能实时显示当前接收的台站与信号**。

本清单把验收拆成可勾选步骤，供在真机上逐项执行。

## 1. 前置准备

| 项 | 要求 |
| --- | --- |
| 设备 | Android 真机（本项目在 vivo V2338A / `10CE5Z1GSZ001TM` 上验证过 USB 调试） |
| 权限 | 开发者选项已开启「USB 调试（安全设置）」与「通过 USB 安装应用」 |
| 音频 | 声学耦合（手机麦克风 ↔ 电台扬声器、手机扬声器 ↔ 电台麦克风）或 USB 声卡/OTG 线缆 |
| 对端 | 另一台运行 WSJT-X 或 FT8CN 的电台，或监听同一波段的友台 |
| 工具 | `adb`（`C:\Users\wty\AppData\Local\Android\Sdk\platform-tools\adb.exe`），真机与模拟器同时在线时用 `-s <serial>` 指定 |
| 合法 | 确认发射功率/频率符合所在地区无线电管理法规，并对发射行为负责 |

安装本次构建：

```powershell
adb -s <serial> install -r app/build/outputs/apk/debug/app-debug.apk
```

> 提示：`connectedDebugAndroidTest` 会重装并清空 App 数据，回归前不要执行它，或在回归前重新填写台站信息。

## 2. 回归步骤

### A. 启动与设置（新 UI 设置页，8 组）

> 带 `U7` 徽标的项在接通后端前为置灰只读，本小节只需确认它们**可回读默认值且不崩溃**（真正生效见 U7）。

- [ ] 首次启动进入「操作」页，呼号/网格未填时顶部报红提示「请到「设置」填写呼号与网格后再发射」。
- [ ] **台站**：呼号留空显示错误态与「发射前必须填写呼号」；网格填非法值（如 `ZZ99`）报错、填 `PM95` 后恢复；「当前波段」下拉可选并回读；备注填 `QRP 5W`，说明提示「自动写入新通联记录的 COMMENT」并注明会追加 `Distance: …`。
- [ ] **电台（仅 VOX）**：**VOX 触发（音频/静音检测）、VOX 延迟、VOX 阈值、发射前导音+时长、测试音、PTT 延迟、看门狗** 均可改（U7b 已点亮）并持久化；点「测试音」应听到 1 kHz 单音且下方电平条随输入变化（无音频输入时显示 `--`/较低 dB）；**输出声卡**下拉可选实际输出设备（U7c 已点亮）。
- [ ] **音频**：输入设备（U7c 已点亮）下拉列出实际输入设备（首项「系统默认」）；采样率偏好（自动/48000/44100/96000）可改，下次「开始接收」生效并在状态栏显示实际值；输入增益（U7c 已点亮）可改并热生效（调大时状态栏 VOX 读数随之升高）。
- [ ] **FT8**：模式可在 FT8/FT4 间切换并持久化；发射偏移（U7）置灰；解码深度 快/标准/深 + 高级参数改动后出现「自定义」；Hold Tx、自动程序（等级 + 策略开关，见 E 组）、最大重试次数可改并持久化；「恢复」（保留台站信息）后其余回落默认。
- [ ] **高亮与提醒**：关闭「新 DXCC / 新 ITU / 新 CQ 区域 / 新网格 / 新前缀 / 新呼号」后，操作页对应高亮与标记点消失（其余优先级仍生效）；已通联实体的不同呼号区不再判为「新 DXCC / 新 ITU / 新 CQ 区域」；「已通联」切 删除线/下划线/隐藏（隐藏时解码列表不再显示已通联行）；末端「红=有我 / 蓝=正通联」标记开关即时生效；含我呼号哔声（U7d 已点亮）开关可改并持久化。每个开关**右侧有对应颜色小圆点**（新网格紫 / 新呼号粉 / 新 DXCC·ITU·CQ 区域·新前缀棕 / 已通联红 / 末端标记红·蓝；「含我呼号哔声」无圆点）；组尾有**固定颜色图例**（不受上面开关影响）：黄=正在发射、蓝=与我有关·当前对手、橙=CQ、灰=重复、绿=其余新解码，暗/亮主题下都清晰可辨。
- [ ] **外观**：主题「暗/亮」即时全局切换且**重启后保留**（亮色下卡片/文字/底栏随主题，地图底图与瀑布仍固定深色）；字体「小/中/大」即时缩放且触摸目标仍 ≥48dp；瀑布高度切「紧凑/标准/高」回操作页生效；「恢复布局」把瀑布高度/字体回默认（原「瀑布配色」设置项已删除）。
- [ ] **日志**：本组内 ADIF 导入/导出按钮可用；清空需二次确认（含条数）；组内**不再有** CloudLog / LoTW / eQSL 上传与局域网后台（已删除，见 `NEW-UI-PLAN.md` §收尾）。
- [ ] **关于**：显示版本号、GPL-3.0 许可与合规提醒。
- [ ] 杀进程重启：以上可改项全部保留（DataStore 持久化）。

### B. 接收

- [ ] 点「开始接收」授予录音权限后，状态栏出现「接收中 / 时隙 N ms / 已解码时隙」并递增。
- [ ] 偶/奇周期行背景分色；时隙进度条推进；「丢帧」计数不持续快速增长。
- [ ] 有信号时解码列表出现报文（时间 / SNR / DT / DF / 文本）。
- [ ] 过滤：CQ only、「排除已通联」、呼号/前缀过滤即时生效；「显示 X / Y」正确。
- [ ] 高亮：色条取命中的最高优先级 —— 正在发射（黄底黑字）、与我有关/当前对手（蓝）、CQ（橙）、已通联（红）、重复（灰）、新网格（紫）、新 DXCC/ITU/CQ 区域与新前缀（棕）、新呼号（粉）、其余（绿）；色条颜色与设置页「高亮与提醒」开关右侧色点、组尾固定颜色图例一致。
- [ ] 点解码行 → 绿线（RX）移到该频率；Hold Tx 关时红线（TX）跟随，开时只动 RX。
- [ ] 解码列表无内容时显示空态文案（未开始接收 / 暂无解码 / 被过滤），三者可区分。

### C. 真实通联（**核心验收**）

- [ ] 与对端约定：同一波段、同一协议（FT8/FT4）、相对周期（我偶他奇或反之）。
- [ ] **周期必须相反（关键）**：对端在第 1/3 个时隙（偶）发 CQ 时，我自动发在第 2/4 个（奇）；对端在奇时我发偶。双方**绝不同周期发射**。
- [ ] **标准节奏**：`CQ → 应答 → 报告 → R报告 → RR73` 依次落在**相邻时隙**（约 75 s 完成整段），而不是每条都白等一个周期。
- [ ] 展开操作页底部发射抽屉，点「CQ」→ 确认弹窗显示呼号/频率/周期/协议 → 确认后按时隙发射 CQ。
- [ ] 对端应答后，我方自动按序列推进：收报告 → 发 `R+报告` → 收 `RR73`/`73` → 完成。
- [ ] 或反向：对端发 CQ，点其解码行「应答」→ 自动完成整段序列。
- [ ] 中途无回复时按「最大重试次数」重发；超过后放弃并回到空闲。
- [ ] 抽屉里的「停止」/「取消目标」立即静音，状态回到空闲；再次开始可正常发射。
- [ ] 发射仅在我方周期时隙窗口内，其余时间静音（对端不应在非窗口时段听到信号）。
- [ ] 收到对方**最后一条** `RR73` 后，我方回 `73` 必须仍在我方周期（对端在相反周期监听）；不得因周期重锁而发到错误时隙。
- [ ] 自动化：启用自动程序后，同一段 QSO 能**连续跑完并落库**，不需要人工干预（见 E 组）。

### D. QSO 自动落库（**端到端**）

- [ ] QSO 完成后操作页「最近通联」出现该条（呼号/网格/收发报告/波段）。
- [ ] 日志页「共 N 条记录」+1，列表出现该条，底部统计「QSO / DXCC / 网格 / 确认」同步。
- [ ] 该条记录：`MY_CALL`/`MY_GRID` 为记录时的快照；`COMMENT` = 自动备注 `Distance: 1738 km, QSO by Ft8Vox`（双方网格齐全时；格式与 FT8CN 一致），若设置里填了台站备注则为 `台站备注, Distance: …`；任一方缺网格时只留 `QSO by Ft8Vox`。
- [ ] 切到其它 Tab 再切回，记录仍在（已从内存态切到 Room）。
- [ ] 杀进程重启后记录仍在。

### E. 自动程序（取代 Call 1st）

- [ ] 顶栏菜单「自动程序」打开设置弹窗：等级单选（0/1/2/3/4+）与 6 个策略开关均可改并持久化。
- [ ] 设置页 6.3 内嵌同一套自动程序面板，改动与顶栏弹窗一致、重启回读一致。
- [ ] 发射抽屉「自动程序」行：显示当前等级摘要；点「设置…」打开同一弹窗（**没有独立的启用/关闭按钮**，等级即开关）。
- [ ] **等级即开关**：从「0 手动选择」切到 1+ 时弹出防误发确认（含呼号/频率/时隙/单次通联提示），确认后等级写入设置并立即生效；切回「0 手动选择」立即停止自动化（**不动发送总开关**）；1+ 之间互相切换不再弹确认（顶栏弹窗与设置页同样会弹确认）。
- [ ] 等级 1：本时隙**最先解码到**的 CQ 被自动应答（不按强度排序）。
- [ ] 等级 2/3：本时隙**最强 SNR** 的 CQ 被自动应答；开启「最远距离取代最佳信噪比」后改为**最远网格**优先。
- [ ] 等级 4+：本时隙无可答 CQ 时自动发 CQ；有人应答后照常进入 QSO。
- [ ] **被呼自动应答**：`<我呼号> <对方> <网格>`（对方呼叫我）→ 自动发信号报告并跑完 QSO；`<我呼号> <对方> <报告>` → 自动回 `R<报告>` 等 RR73；`<我呼号> <对方> R<报告>` → 自动回 `RR73` 并即时落库。
- [ ] 发给别人的报文、以及 `73`/`RR73`/`RRR` 不会触发自动应答（不开启新 QSO）。
- [ ] 「回答/呼叫曾经通联的电台」关闭时跳过日志中已有的呼号；开启后已通联台可被应答。
- [ ] 「优先选择新呼号」开启时，新呼号优先于已通联台（条件相近时）。
- [ ] 「报告信息优先」开启时，发给我方的定向报文在排序上优先于 CQ（关闭时与 CQ 一起按 SNR/距离排序）。
- [ ] **时隙自动对应**：被自动应答的目标在**相反周期**收发（对方第 1/3 个时隙则我发第 2/4 个）。
- [ ] **时隙稳定（不跳时隙）**：一次 QSO 完成后发射周期**保持不变**（如一直是偶），不会因按当前时间重锁而在偶/奇之间来回跳；只有下一目标在相反周期时才切换（此时必须切换）。手动「发送 CQ」、失败重试同样沿用当前周期。
- [ ] **超时重试 / 失败续台**：QSO 中对方不回复时每个时隙重发，超过最大重试次数判失败；失败后若该对手仍可解到会**优先重试一次**，之后自动接续下一台，全程无需手动。
- [ ] 「单次通联」默认**关**（连续通联）；开启时一次 QSO 结束即把等级切回「0 手动选择」（＝关闭自动程序，状态栏有说明），关闭时连续自动通联直到把等级切回 0 或关发送总开关。（只停止自动化，**不动发送总开关**。）
- [ ] **关闭总开关不动等级**：关「发送总开关」只停发 + 解除时隙锁定/目标固定，状态栏显示「发送已关闭（只接收）｜自动程序待命」；再开总开关即按原等级继续，不会清掉等级。
- [ ] **停止发射只停本次**：等级 ≥1 时点「停止发射」只中止当前发射（状态栏提示「自动程序仍开启（要全停请关「发送总开关」）」），下一时隙自动程序继续。
- [ ] **确认启用会自动开总开关**：等级从 0 切到 1+ 时，防误发确认里提示会自动打开「发送总开关」；确认后收起态条的 Switch 与「允许发射」文案同步，并开始自动收发（此前总开关若已是「已开」则保持不变）。

### F. 地图页实时标记（**核心验收**）

- [ ] 地图页为全屏深色底图，**无网格线**；底部浮层显示图例（解码/通联/确认/CQ）与统计；右下角浮控为 放大 / 缩小 / 回我的位置。
- [ ] 历史：日志里已有网格的格子按 已通联（黄）/已确认（红）着色；网格统计与日志聚合一致。
- [ ] **实时**：接收中出现对端信号后，「呼号」「连线」计数 > 0；对端有网格时地图按网格中心出现蓝点，无网格时按呼号前缀归属地立点（标记后带 `~`）。
- [ ] 蓝点由本会话解码派生，杀进程重启后清空；黄/红来自日志，重启后仍在。
- [ ] 解码到 CQ 时在该位置出现红色旗；浮层「CQ 呼号 / CQ 强度」开关即时生效。
- [ ] 信号连线只显示最近一个时隙：报告数字 / `RR73` / `73` 沿通信方向运动，其余载荷为移动方块；「连线文字」关掉后全部简化为方块。
- [ ] 点击标记 → 底部浮层显示 呼号/网格(或前缀)/SNR/DF/时间 +「应答」「日志」「清除」；应答走确认弹窗。
- [ ] 操作页双击某条解码卡片 → 自动切到地图页并定位到该呼号。
- [ ] 放大/缩小按钮与双指缩放、单指平移一致；「回我的位置」按我方网格居中放大（未填网格时不动作）。

### G. 日志页（新 UI：筛选 / 统计 / 长按）

- [ ] 波段 / 模式 chip 下拉选择后列表过滤；「日期」chip 弹出区间对话框（UTC，闭区间，可只填一侧，支持 `YYYY-MM-DD` 与 `YYYYMMDD`）；存在任一筛选时出现「清除」chip。
- [ ] 卡片按「呼号 / 网格 / 时间 / RST / 模式」呈现；网格或报告缺失显示 `----` / `--`；已确认（QSL/LoTW=Y）左侧竖条变绿并显示 ✔。
- [ ] 单击卡片进「编辑通联」，字段回显正确，保存后列表即时更新。

- [ ] 编辑页内的「删除」同样先弹二次确认；取消回到编辑框，确认后删除并退出编辑。
- [ ] 底部统计常驻：QSO / DXCC（呼号前缀映射实体表）/ 网格 / 确认 四格 + 波段柱图（柱高按条数比例）。
- [ ] 「⋮」菜单：新增通联、导入 ADIF、导出 ADIF、清空日志（二次确认，含条数与「建议先导出 ADIF」）；无「局域网后台地址」项（已删除）。

### H. 解码参数（生效链路）

- [ ] 「深」预设下同样信号解码条数不少于「快」（可对同一段信号分别观察）。
- [ ] 接收中把「最低得分 / LDPC 迭代 / 候选上限 / 单时隙上限」任一项改动，无需重启即影响后续时隙（解码不中断）。
- [ ] 改「时间/频率 OSR」或频率上下限后，提示「需重启接收」；停止再开始后生效（状态栏频率轴范围随之变化）。

### I. ADIF 导入/导出

- [ ] 导出 ADIF：文件名 `ft8vox_YYYYMMDD.adi`（不被追加 `.txt`），内容含 `ADIF_VER` 头与各记录 `EOR`。
- [ ] 用常见日志软件（如 Log4OM / N1MM / WSJT-X 日志）导入该文件成功。
- [ ] 反向：从外部导出的 ADIF 导入本 App → 提示「新增 X / 更新 U / 跳过 Y」；同一文件再次导入全部跳过（判重口径：呼号+时间+波段+模式，时间容差 ±60s）。
- [ ] **LoTW 确认**：把 LoTW 下载的确认报告（`LOTW_QSL_RCVD=Y`）导入 → 已有记录被点亮为「已确认」（日志列表红色 / 统计卡「确认」+1 / 地图红点变红），条数不变、不产生重复行；同一报告再次导入为「跳过」。
- [ ] 中文备注导入导出往返不乱码（长度按 UTF-8 字节）。
- [ ] 已知限制：打开 SAF 选择器会使 App 进后台并停止接收（阶段 9 前台服务后消除）。

### J. 空态 / 错误态

- [ ] 日志页：无记录时「还没有通联记录」；有记录但筛选无结果时「没有符合筛选条件的记录」。
- [ ] 日志页：呼号未设置时提示「未设置呼号，新记录会缺少 MY_CALL。」并可「去设置」。
- [ ] 操作页：未开始接收 / 暂无解码 / 被过滤三种空态文案正确。
- [ ] 地图页：无标记/无连线时整块保持空白（呼号、网格、CQ、连线计数均为 0），不崩溃。
- [ ] 拒绝录音权限后开始接收 → 不崩溃，给出失败提示。

### K. VOX / PTT（U7b）

> 无 CAT，App 无法读取电台真实键控状态；`voxOpen` 仅为**输入音频活动**的近似提示，以下「键控」项需实际电台验证。

- [ ] 状态栏显示 `VOX -xx dB`（无输入时 `--`）；音频速览（顶栏铃铛图标）显示电平/状态/触发方式/阈值/前导/看门狗。
- [ ] 设置页「测试音 → 播放」发出 1 kHz 单音，下方电平条随输入变化；播报后底部状态条 `VOX` 值随之刷新。
- [ ] VOX 触发切「静音检测」后，安静信道下 `voxOpen` 置位（状态条出现 `●`）；切回「音频检测」在同样条件下不置位。（阈值/延迟可调，需等待去抖时长。）
- [ ] **前导音键控（真机）**：开「发射前导音」并把时长设 200–500 ms，配合电台 VOX；发射时电台应在 FT8 数据到达前完成键控，波形起点不被截断。注意前导音与 FT8 波形之间还有 0.5 s 保护静音，电台 VOX 的释放延时需覆盖该间隔。
- [ ] **PTT 延迟（真机）**：使用 USB 声卡/OTG 时，把「PTT 延迟」设 50–200 ms，减少数据起始被截断。
- [ ] **时隙对齐（真机/示波器或另一台接收机）**：无论前导多长，FT8 数据应仍落在时隙起点（`planTx` 会提前相应时长启动）。
- [ ] 「看门狗超时」改动不影响正常发射（整时隙约 15 s 仍能写完，不发生中途中止）。
- [ ] **已知边界**：无 CAT 时无法确认电台是否真正发射；VOX 键控失败时 App 无从感知。

### L. 音频路由 / 增益 / 提示音（U7c / U7d）

- [ ] 设置页 6.1「输出声卡」下拉列出「系统默认」+ 实际输出设备（内置扬声器/USB/蓝牙等）；选中后返回再进仍回读同一设备。
- [ ] 设置页 6.2「输入设备」下拉列出「系统默认」+ 实际输入设备（内置麦克风/USB 等）；选中后**重新开始接收**，状态栏输入采样率按该设备刷新。
- [ ] 插入 USB 声卡/OTG 后**重进设置页**，列表中应出现该设备；选中后发射/接收走 USB 声卡。
- [ ] 「输入增益」改动热生效（无需重启接收）；调大增益时状态栏 VOX 电平读数随之升高；极端大增益下不出现回绕爆音（限幅到满幅）。
- [ ] 运行中切换输入设备 → 提示「输入设备将在下次开始接收生效」，不打断当前接收。
- [ ] 发射中切换输出设备 → 提示「输出声卡将在下次发射生效」，不中断本次发射。
- [ ] **含我呼号哔声（U7d）**：开启后，收到直接呼叫我方呼号的报文（如 `我的呼号 对方 -08`）应听到一声短提示音；CQ 与他台之间的通联不触发；关闭后不再响。
- [ ] 无音频输入/无提示音通道的设备上不应崩溃（静默降级）。

### M. 波段 / 频率 / 发送总开关 / 自动周期（U8 / U9 补记 4）

- [ ] 顶栏菜单「波段与频率」打开弹窗，列出各波段及其多个常用刻度频率；点选任一频率后顶栏 `MHz` 立即更新，返回再开仍标 `●`。
- [ ] 弹窗「自定义波段与频率…」可输入波段名与 MHz（如 `试验` + `13.500`），确认后顶栏频率更新；非法/非正数时不放行；自定义值重启后回读一致。
- [ ] 设置页「台站 → 波段与频率」复用同一弹窗，选中后与顶栏一致。
- [ ] 记录一条通联，ADIF 的 `BAND` 与 `FREQ` 与所选「波段 + 频率」一致；自定义波段导出为自定义名 + 精确 `FREQ`。
- [ ] 发射抽屉**收起态 56dp 条**上的「发送总开关」默认**关**（每次启动都默认只接收），条中第二行显示「只接收」、「发送」按钮禁用、防误发弹窗「确认发射」禁用。
- [ ] **打开总开关只授权，不发射任何报文**（旧「打开即发默认动作」已移除）；打开后第二行显示「允许发射」、「发送」按钮可用。关闭总开关应立即停发、解除时隙锁定（**不动自动程序等级**：抽屉「自动程序」行仍显示原等级，只是待命）。
- [ ] 设置页不再有「默认发射周期」项；时隙恒为「自动」（按手机 UTC 时间取下一个来得及的时隙）。
- [ ] **顶栏时隙指示（0/1 号，三行）**：第 2 行接收时隙为 `· RX：n`、我方发射时隙为 `· TX：n`（n = 0/1，TX 取锁定的发射周期，RX 取当前时隙）；第 3 行在**我方发射时隙且有待发报文/正在发射**时出现 —— `待发 <报文>`（蓝）或 `发射中 <报文>`（红，回退显示刚发出的那条），接收时隙无第 3 行；关闭发送总开关／未开始接收时第 2/3 行时隙段整段不显示；三行紧凑行高，顶栏高度保持 56dp 不跳动；报文过长自动省略号截断。
- [ ] 无目标/无自定义文本/无队列时，展开面板的「发送」默认发起 CQ（走防误发确认）；已选目标时默认应答该目标。（收起态开关不再触发发送。）
- [ ] **自动时隙（真机/示波器或另一台接收机）**：开启总开关并经「发送」触发发射后，音频应落在**下一个来得及的时隙**（当前时隙剩余不足前导则跳到再下一个）；应答对方时落在其**相反周期**；同一 QSO 内时隙不跳变。
- [ ] 关闭总开关再重新打开，会按当前 UTC 时间重新锁定时隙（用于换到另一个奇偶周期）。

## 5. 已知限制（本阶段不做）

- Hound/Fox（DXpedition）、标准序列之外的变体（`TU;` 等）、比赛报文。
- 在线地图瓦片、逐条呼号的精确 DXCC 判定（当前为呼号前缀映射实体表，详见 U7a）、海岸线底图（`BaseMapLayer` 预留）、**离线瓦片**（缺瓦片数据源）。
- FST4：`ft8_lib` 仅含 FT8/FT4 调制解调，FST4 需自研（LDPC/多符号速率/GFSK），**明确不做**；模式菜单仅 FT8/FT4。
- 局域网后台 / 在线日志（CloudLog / LoTW / eQSL）：**不做**（占位项已删除）；瀑布配色：**不做**（占位项已删除）。
- 音频设备 id 可能随插拔/重启变化，设置里存的是原始 id 字符串；失配时界面回退显示「系统默认」但发射/接收仍走系统默认（U7c）。
- 「含我呼号哔声」走系统通知流（`ToneGenerator`），与 FT8 发射流（媒体流）分离；声学耦合场景下提示音可能被电台拾取，可关闭（U7d）。
- 无 CAT：无法读取电台真实 PTT/VOX 键控状态，`voxOpen` 仅为输入音频活动的近似提示，不参与发射门控；VOX 键控失败时 App 无从感知（U7b）。
- CAT 频率控制（无 CAT，波段由人工指定）。
- 打开 SAF 选择器会触发 `onStop` 停止接收。
- 发射时不静音接收。
