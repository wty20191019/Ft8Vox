# Ft8Vox · 手机竖屏界面重设计（v2）

> 本文是「**放弃旧外壳，按手机触屏重做**」这一轮的设计准绳。
> 它**取代** `docs/UI-JTDX.md` 中「菜单栏 + 左侧竖导航 + 横屏外壳」那一整套形态；
> `docs/UI.md` 里的深色板、解码逻辑、JNI 契约、路线图、测试回归清单仍然有效。
>
> 决策来源：2026-09-29 与用户的**六轮问答**，逐条结论见 §1。
> 状态：**设计稿，等用户确认后再动代码**。

## 1. 决策记录（六轮问答结论）

| 决策点 | 结论 |
| --- | --- |
| 设计基准 | **不照搬桌面**，按手机触屏习惯重做（控件大、层级浅、一屏一件事） |
| 屏幕方向 | **强制竖屏**（`sensorPortrait`） |
| 要治的病 | ① 操作路径太长 ② 太挤 / 装不下 |
| 核心场景 | 看解码列表 + 快速呼叫；看瀑布 + 调发射频率（两者并重） |
| 瀑布与解码 | **两个整页 Tab 切换**：操作页全屏解码，频谱页全屏瀑布 |
| 底部导航 | **5 项**：操作 / 频谱 / 地图 / 日志 / 设置，**图标 + 文字** |
| 解码行 | **单行表格 6 列**：时隙 / UTC / 分贝 / 时差 / 频率 / 信息 |
| 解码行高亮 | **照搬 JTDX 默认的「整行底色」**（色表见 §6） |
| 快速呼叫 | **保留左右滑手势**（左滑呼叫 / 右滑删除） |
| 六个报文槽 | **底部常驻**，竖屏放不下 → **3 列 × 2 行**，槽上**直接写报文内容** |
| 发射闸门 | **顶部一个总开关**（唯一闸门，默认关 = 只接收） |
| 顶部信息 | **三行紧凑**：频率+波段 / 时钟+时隙进度+电平 / 呼号+网格+DX 目标 |
| 频谱页 | 瀑布铺满 + 频率刻度 + 发射频率数字 + **可拖红线** + **把解码映射到频谱**（按频率位置标呼号文字、按类别上色、留最近 2–3 个时隙） |
| 频谱设频 | **拖动红线** |
| 状态条 | 顶部已有信息，**底部仍保留一条细状态条** |
| 日志页 | **统计卡 + 卡片列表** |
| 设置页 | **单页长列表** |
| 地图页 | **保留世界网格图**，只重做外观与手势 |
| 配色 | **保留现有深色板 + 绿色高亮** |
| 主题 / 字号 | **亮/暗切换、字体档位都去掉**（只有暗色 + 固定字号） |
| 其余三页 | **一起重做** |

## 2. 屏幕骨架（竖屏）

```
┌──────────────────────────────────┐
│ 14.074 000    20m·FT8   [总开关 关]│ ① 信息头 第1行
│ UTC 11:56:08   时隙 ▓▓▓░░ 3/15  ▮│ ②         第2行
│ BG7ZZZ OM89    DX→JA1ABC PM95 -15 │ ③         第3行
├──────────────────────────────────┤
│ [过滤…] [清除] [关注 3]   筛选:… │ ④ 过滤行
├──────────────────────────────────┤
│ 时隙  UTC    分贝 时差 频率  信息 │ ⑤ 表头
│ ▓ CQ JA1ABC PM95                 │ ⑥ 解码列表
│ ▓ JA1ABC BG7ZZZ -15              │   （整行底色高亮）
│ …                                │   ← 主体，尽量多行
├──────────────────────────────────┤
│ [生成信息][自定义报文__][CQ 无▾][发送]│ ⑦ 发射区 第1行
│ [停止发射]            [自动程序]  │ ⑧        第2行
│ ┌网格───┐┌报告───┐┌R报告──┐      │ ⑨ 报文槽 3×2
│ ┌RR73───┐┌ 73 ───┐┌ CQ ───┐      │ ⑩
├──────────────────────────────────┤
│  ▭操作  ▭频谱  ▭地图  ▭日志  ▭设置│ ⑪ 底部导航
├──────────────────────────────────┤
│ 接收 FT8 解码12/min 总123 QSO7 …  │ ⑫ 细状态条
└──────────────────────────────────┘
```

固定高度合计约 **360dp**，普通竖屏手机（可用 ~750dp）留给解码列表 **约 390dp ≈ 19 行**，
彻底解决上一版「解码列表被挤成 0 高度」的问题。

## 3. 操作页

### 3.1 信息头（三行，全局常驻）

| 行 | 左 | 中 | 右 |
| --- | --- | --- | --- |
| 1 | 大频率 `14.074 000` + `20m·FT8` | — | **发送总开关**（方块，开=绿底） |
| 2 | `UTC 11:56:08` | 时隙进度条 `▓▓▓░░ 3/15` | 输入电平竖条（VOX） |
| 3 | 我方 `BG7ZZZ OM89` | `DX→JA1ABC PM95 -15` | 接收状态点 |

- 频率 = `status.dialHz`；波段/模式 = `status.band` / `status.protocol`。
- 时钟 = `QsoTime.isoTime(nowMs)`；时隙进度 = `slotProgress × slotMs`。
- DX 目标 = 当前 `qso.theirCall` / 最近一条该台解码的网格 / `reportSent`。
- 未设置呼号时整行第 3 行变红：`请先到设置填写呼号与网格`。
- **发送总开关**放第 1 行最右，始终可见；关=「只接收」，开=「允许发射」。

### 3.2 过滤行（一行）

`[过滤…]`（弹窗：六个 Chip + 呼号/前缀/网格搜索）`[清除]` `[关注 N]`（弹窗：关注列表），
右侧小字 `筛选：…`。保持旧版语义，只是不再有菜单栏入口。

### 3.3 解码列表

- 单行 6 列，等宽小字：`时隙 / UTC / 分贝 / 时差 / 频率 / 信息`。
- **整行底色高亮**，颜色取命中类别的最高优先级（§6）。
- 行高 ~20dp，一屏 ~19 行；新解码自动吸顶（沿用现有 `followNewest` 逻辑）。
- 空态文案沿用纯函数 `decodeEmptyHint`（已有单测，不要改名）。

### 3.4 发射区（底部）

- 第 ⑦ 行（一行同时放自定义报文与 CQ 前缀）：
  `[生成信息]` `[自定义报文 ______]` `[CQ 前缀 无 ▾]` `[发送]`（自定义为空则置灰）。
- 第 ⑧ 行：`[停止发射]`（红，仅在发射中可用）`[自动程序]`（弹窗）。
- 第 ⑨⑩ 行：**六个报文槽 3×2**，槽上直接写报文内容（两行文本可换行，不再截断）：

| 槽 | `TxMessageKind` | 内容 | 点击 |
| --- | --- | --- | --- |
| 网格 | `GRID` | `目标 我 网格` | `sendOnce` |
| 报告 | `REPORT` | `目标 我 报告` | `sendOnce` |
| R报告 | `ROGER` | `目标 我 R报告` | `sendOnce` |
| RR73 | `RR73` | `目标 我 RR73` | `sendOnce` |
| 73 | `SEVENTY_THREE` | `目标 我 73` | `sendOnce` |
| CQ | `CQ` | `CQ <前缀> 我 网格` | `startCq` |

- 槽内容**不持久化**，每帧由 `TxCompose.compose` 现算，永远与六步序列一致。
- 目标为空时 Tx1–Tx5 置灰；指示灯：该槽报文 == `status.displayTxText` 时点亮。
- 闸门仍是**发送总开关**；关闭时点击由 `SessionViewModel` 拦下并提示，不弹确认框。

## 4. 频谱页

```
┌──────────────────────────────────┐
│ （全局信息头三行）                │
├──────────────────────────────────┤
│ 发射频率 1234 Hz     20m·FT8      │ 频率读数（随红线走）
├──────────────────────────────────┤
│                                  │
│        瀑  布  铺  满             │ ① 瀑布本体
│   CQ JA1ABC  ▏  BG7ZZZ   ▏       │ ② 解码文字叠加（按频率位置）
│ ────────────────────────────     │ ③ 横轴频率刻度（kHz）
│      ▲红线 = 发射频率（可拖动）   │ ④
├──────────────────────────────────┤
│  ▭操作  ▭频谱  ▭地图 ▭日志 ▭设置  │
├──────────────────────────────────┤
│ （细状态条）                      │
└──────────────────────────────────┘
```

- **瀑布铺满**内容区；横轴是音频频率刻度（`0 … 3000 Hz`，按 `decode.fMaxHz` 自适应）。
- **可拖红线** = 发射频率（报文**下边频**）；水平拖动红线设频，读数实时更新并持久化。
- **解码映射到频谱**：在每条解码的 `df` 位置标出**呼号文字**，颜色用该条的 JTDX 类别色（§6），
  只保留**最近 2–3 个时隙**，过期自动淡出/消失，避免糊屏。
- 文字为**只读展示**（本轮不做「点频谱文字直接呼叫」，避免误触）。
- 频谱页**不显示底部六个报文槽**（让瀑布尽量大）；要发射切回操作页。
- 右下角保留 `TX xxxx Hz` 读数 + 贴底时隙进度条（沿用现有实现）。

## 6. 解码行高亮（照搬 JTDX / WSJT-X 默认）

数据来源：WSJT-X `DecodeHighlightingModel::defaults_`（JTDX 继承同一套默认）。
**形式一律是「整行底色」**（深色板上会按 ~35% 不透明度铺底，保证文字仍清晰可读）。

| 类别 | 默认底色 | 默认开 |
| --- | --- | --- |
| 自己发的（Transmitted） | 黄 `#FFFF00` | ✔ |
| 叫我（My Call in message） | 红 `#FF6666` | ✔ |
| CQ in message | 绿 `#66FF66` | ✔ |
| 新 DXCC / 本波段新 DXCC | 品红 `#FF00FF` / `#FFAAFF` | ✔ |
| 新网格 / 本波段新网格 | 橙 `#FF8000` / `#FFCC99` | 默认关（按本应用设置开关） |
| 新呼号 / 本波段新呼号 | 青 `#00FFFF` / `#99FFFF` | 默认关（按本应用设置开关） |
| 新大陆 / 本波段 | `#FF0063` / `#FF99C2` | ✔ |
| 新 CQ 区 / 本波段 | `#FFBF00` / `#FFE499` | ✔ |
| 新 ITU 区 / 本波段 | `#A6FF00` / `#DDFF99` | 默认关 |
| LoTW 用户 | 前景 `#990000` | 默认关 |

**优先级**（命中多个时取最高）：

1. **自己发的 / 正在发射**（本应用会把「自己发的解码行」显示在列表里，所以提到最高，保证黄底）
2. 叫我（红）
3. 新大陆 → 新 CQ 区 → 新 ITU 区
4. 新 DXCC → 新网格 → 新呼号（按设置页开关）
5. CQ（绿）
6. 已通联（**不上底色**，用现有「删除线 / 下划线 / 隐藏」表达）
7. 重复（**不上底色**，整体降透明度）
8. 其余（无底色）

> 本应用的「新前缀」归入「新 DXCC」同一底色；「已通联 / 重复」沿用现有的弱化表达
> （JTDX 里 worked-before 也是弱化而不是另给一种颜色）。

## 8. 交互与手势

| 操作 | 行为 |
| --- | --- |
| 解码行**单击** | 设为目标 + 对频 |
| 解码行**双击** | 跳地图页并定位该呼号 |
| 解码行**长按** | 菜单：呼叫 / 回复 / 详情 / 日志 / 复制 / 关注 / 忽略 |
| 解码行**左滑** | 设为目标并呼叫（绿条提示） |
| 解码行**右滑** | 删除该条（灰条提示） |
| 频谱**拖动红线** | 设发射频率（读数实时更新、重启保留） |
| 报文槽**点击** | 立即排程发射（CQ 槽走 `startCq`） |
| 发送总开关 | 唯一发射闸门；关=只接收，点击槽/发送只提示不发射 |
| 「过滤…」 | 筛选弹窗（六 Chip + 搜索） |
| 「关注 N」 | 关注列表弹窗（左滑呼叫 / 右滑取消关注） |
| 「自动程序」 | 自动程序弹窗（四项策略） |
| 返回键 | 接收中退到后台继续接收；弹窗打开时先关弹窗 |

**保留**：所有「点下即排程、无确认框」的既有语义；`ReceiverStatus.txEnabled` 仍是唯一闸门。
**移除**：JTDX 菜单栏、左侧竖导航、信息头下控制行、亮/暗主题切换、字体档位、横屏。

## 12. 第七轮补充确认（已定）

1. **自定义报文行 + CQ 前缀入口合并成同一行**（§3.4 第 ⑦ 行）。
2. **手动输入 DX 呼号 / 网格 + 「呼叫」放设置页「台站」组**，操作页不占位。
3. **频谱上的解码呼号只读**，不响应点击（防误触）。
4. **频谱横轴用音频频率 Hz**（`0…fMaxHz`）。
5. **底部导航用 `material-icons-core` 现有图标**（候选见 §7），不自绘。

未单独确认、直接按提案默认的小项：

- 日志统计卡指标 = 总通联 / 波段数 / 模式数 / 最近日期。
- 细状态条保留「队列 N」。
- 报文槽 3×2 内文字允许换行、不再截断。
